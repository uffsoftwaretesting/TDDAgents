[Usuário]: Aja como um engenheiro de software especializado em métodos numéricos e
           computação científica, com foco em precisão, determinismo e compatibilidade
           com sistemas automatizados de avaliação rigorosos. Implemente uma função em
           Python chamada adams_bashforth_3(f, t0, y0, t_final, h) que resolva
           numericamente um problema de valor inicial de uma equação diferencial
           ordinária escalar de primeira ordem utilizando o método explícito de Adams
           Bashforth de terceira ordem. A função deve tratar f como uma função pura f(t,
           y) que retorna a derivada dy por dt sem efeitos colaterais e garantir tipagem
           consistente para todos os parâmetros. Como o método é de múltiplos passos,
           inicialize obrigatoriamente os dois primeiros valores adicionais utilizando
           um método de passo único de ordem suficiente como Runge Kutta de quarta ordem
           para obter y1 e y2 a partir de t0 e y0 com passo h. Construa a malha temporal
           de forma robusta assegurando estritamente que o último ponto avaliado seja
           exatamente igual a t_final e, caso o passo nominal h não divida o intervalo
           exatamente, o tamanho do último passo deve ser truncado e ajustado
           dinamicamente para alcançar exatamente t_final sem ultrapassá lo, incluindo
           na etapa final a recomputação consistente das avaliações necessárias de f. A
           partir do terceiro ponto, em cada iteração de tamanho de passo dt, aplique a
           fórmula y_{n+1} igual a y_n mais dt vezes a combinação linear um sobre doze
           de vinte e três f(t_n, y_n) menos dezesseis f(t_{n-1}, y_{n-1}) mais cinco
           f(t_{n-2}, y_{n-2}), garantindo atualização correta e ordenada dos históricos
           de estados e derivadas. A implementação deve ser estritamente determinística
           e deve retornar exclusivamente um valor do tipo float correspondente à
           estimativa final de y em t_final sem retornar listas, arrays ou qualquer
           histórico intermediário.
[Analista]: Checklist de Requisitos Técnico para adams_bashforth_3:

1. Interface e Tipagem
1.1. Assinatura: def adams_bashforth_3(
f: Callable[[float, float], float],
t0: float,
y0: float,
t_final: float,
h: float
) -> float
1.2. f deve ser uma função pura que recebe (t: float, y: float) e retorna float sem
efeitos colaterais.
1.3. Todos os parâmetros de entrada (t0, y0, t_final, h) e o valor de retorno devem ser
do tipo float.
1.4. Validações iniciais:
• f é callable.
• t0, y0, t_final, h são floats.
• h > 0.
• t_final >= t0.

2. Malha Temporal Robusta
2.1. Calcular número de passos completos N = floor((t_final – t0) / h).
2.2. Calcular passo final truncado: dt_last = (t_final – t0) – N * h.
2.3. Garantir que o último ponto avaliado coincide exatamente com t_final, ajustando dt
= dt_last se dt_last > 0.

3. Inicialização via RK4 (ordem 4)
3.1. A partir de (t0, y0), usar RK4 com passo h para obter y1 em t1 = t0 + h.
3.2. Em seguida, usar RK4 novamente a partir de (t1, y1) com passo h para obter y2 em t2
= t0 + 2*h.
3.3. Cada etapa de RK4 deve recomputar f nas subetapas com tipagem coerente.

4. Histórico de Estados e Derivadas
4.1. Manter as últimas três tuplas (t_{n-2}, y_{n-2}, f_{n-2}), (t_{n-1}, y_{n-1},
f_{n-1}), (t_n, y_n, f_n).
4.2. Atualizar o histórico a cada iteração, descartando o mais antigo.

5. Iteração Adams–Bashforth de 3º ordem
5.1. Para cada passo n = 2 até N:
• Definir dt = h, exceto se n == N e dt_last > 0, então dt = dt_last.
• Recalcular f_{n}, f_{n-1}, f_{n-2} em (t, y).
• Aplicar fórmula:
y_{n+1} = y_n + dt * (1/12) * (23*f_n – 16*f_{n-1} + 5*f_{n-2}).
• Avançar t_{n+1} = t_n + dt.
• Atualizar histórico de estados e derivadas.

6. Determinismo e Robustez
6.1. Não usar variáveis estáticas ou aleatórias.
6.2. Todas as operações em ponto flutuante devem seguir a mesma ordem de execução em
cada chamada.

7. Tratamento de Erros e Exceções
7.1. Lançar TypeError se tipos de entrada não corresponderem.
7.2. Lançar ValueError se h <= 0 ou t_final < t0.

8. Retorno
8.1. Retornar exclusivamente o valor final y(t_final) como float.
8.2. Não retornar listas, arrays ou histórico de passos.
