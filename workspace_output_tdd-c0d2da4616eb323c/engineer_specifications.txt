# Especificação Técnica: Módulo de Quadratura Numérica – integracao_trapezio

## 1. Visão Geral do Sistema
A rotina `integracao_trapezio` aproxima o valor de integrais definidas em um intervalo [a, b] utilizando a Regra do Trapézio Composta ou uma abordagem adaptativa baseada em tolerância de erro. A escolha do modo é feita via parâmetros opcionais: número de subintervalos `N` (modo composto) ou tolerância `tol` (modo adaptativo). Em caso de conflito, a tolerância prevalece.

## 2. Estruturas de Dados e Interfaces

Assinatura:
  def integracao_trapezio(
    f: Callable[[float], float],
    a: float,
    b: float,
    N: Optional[int] = None,
    tol: Optional[float] = None
  ) -> float

Parâmetros:
- f: Callable[[float], float]  
  * Função escalar integranda. Ao ser chamada com um `float`, retorna um `float`.
- a: float  
  * Limite inferior de integração.
- b: float  
  * Limite superior de integração. Deve satisfazer a < b ou a == b.
- N: Optional[int]  
  * Número de subintervalos para a Regra Composta. Deve ser inteiro maior que zero. Ignorado se `tol` for fornecida.
- tol: Optional[float]  
  * Tolerância de erro para integração adaptativa. Deve ser float maior que zero. Prevalece sobre `N`.

Retorno:
- float  
  * Aproximação da integral ∫ₐᵇ f(x) dx.

Exceções:
- TypeError ou ValueError conforme cenário de validação descrito na Seção 3.

## 3. Casos de Borda e Validações (Edge Cases)

Validações de tipos e valores:
- f  
  * Se não for callable: TypeError("f deve ser uma função Callable[[float], float]").  
  * Se f(x) não retornar float em qualquer avaliação: propagação de TypeError.
- a, b  
  * Se não forem floats: TypeError("a e b devem ser floats").  
  * Se a > b: ValueError("a deve ser menor que b").  
  * Se a == b: retorna 0.0 sem chamar f.
- Parâmetros de modo  
  * Se `tol` e `N` forem ambos None: ValueError("É preciso fornecer N ou tol").  
  * Se `tol` for fornecida e não for float > 0: ValueError("tol deve ser float positivo").  
  * Se `tol` for float > 0 e `N` também fornecido: ignora `N`, opera em modo adaptativo.  
  * Se `tol` for None e `N` não for int > 0: ValueError("N deve ser int positivo").

Regra Composta:
- Passos de cálculo devem usar apenas operações escalares:
  1. h = (b – a) / N  
  2. soma = 0.5⋅(f(a) + f(b)) + Σ₍ᵢ₌₁…N₋₁₎ f(a + i⋅h)  
  3. resultado = h × soma

Regra Adaptativa:
- Iteração com N₀ = 1  
- Para k = 1…MaxIter (ex: 20):
  1. Calcular Tₖ usando Regra Composta com Nₖ = 2·Nₖ₋₁  
  2. erro_est = |Tₖ – Tₖ₋₁| / 3  
  3. Se erro_est ≤ tol: retorna Tₖ  
- Se exceder MaxIter sem convergir: ValueError("Não convergiu em até {MaxIter} iterações")

## 4. Contexto Técnico
- Linguagem alvo: Python 3.8+  
- Paradigma: imperativo, sem vetorização; operações escalares e laços `for`.  
- Sem dependência de NumPy ou outros frameworks de vetorização.  
- Precisão controlada via `tol`; estimativa de erro adaptativa baseada em diferença de ordens sucessivas da Regra do Trapézio (fator 1/3).  
- Documentação interna via docstring padrão num estilo Google ou NumPy docstring.

## 5. Dependências Base (Core Dependencies)
- Python Standard Library  
  * typing (Callable, Optional)  
- Ferramenta de testes  
  * pytest (padrão-ouro para TDD em Python)
