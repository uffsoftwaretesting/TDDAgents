PLANO DE SUB-REQUISITOS TDD
================================================================================
1. FASE 0 - SETUP: Instalar pytest na sandbox; criar a estrutura de diretórios src/ e tests/; adicionar arquivos __init__.py em ambos; criar esqueleto de src/integracao_trapezio.py e tests/test_integracao_trapezio.py vazios.
2. FASE 1 - VALIDAÇÕES DE PARÂMETROS: Em src/integracao_trapezio.py, definir stub da função integracao_trapezio com checagens iniciais de tipo/valor (f não callable, a/b não float, a>b, ambos N e tol None, tol <=0, N <=0) sem lógica de cálculo; em tests/test_integracao_trapezio.py, implementar testes unitários para cada cenário de exceção e garantir que TypeError e ValueError sejam lançados conforme especificado.
3. FASE 2 - CASO A == B: Estender integracao_trapezio para retornar 0.0 imediatamente quando a == b; criar testes que cubram diferentes f (incluindo função que lançaria erro se chamada) e verifiquem retorno exato 0.0 sem invocar f.
4. FASE 3 - MÓDULO DA REGRA COMPOSTA: Em src/integracao_trapezio.py, implementar função interna _trapezio_composto(f, a, b, N) com cálculo h, soma e resultado; acrescentar testes unitários parametrizados para funções polinomiais simples (ex: f(x)=x, f(x)=x**2) validando resultados exatos para vários N.
5. FASE 4 - MÓDULO DA REGRA ADAPTATIVA: Implementar _integracao_adaptativa(f, a, b, tol, max_iter=20) que itera duplicando N e calcula erro_est <= tol; lançar ValueError se ultrapassar max_iter; criar testes que verifiquem convergência para f monótonas conhecidas e o disparo de exceção quando tol irrealista.
6. FASE 5 - FUNÇÃO PRINCIPAL E ORQUESTRAÇÃO: Completar integracao_trapezio para priorizar tol sobre N, delegar a _trapezio_composto ou _integracao_adaptativa após validações; escrever testes de integração unitários que cubram cenários mistos (tol fornecida + N ignorado, apenas N, somente tol) e confirmem que o modo correto é acionado.
7. FASE 6 - TESTES DE INTEGRAÇÃO COMPLETA E COBERTURA: Adicionar testes parametrizados em tests/test_integracao_trapezio.py para casos gerais (funções trigonométricas via math, integrais em intervalos diversos), validar precisão dentro de tol em múltiplos cenários; configurar pytest.ini para exigir cobertura mínima de 100% nas linhas de src/integracao_trapezio.py.
================================================================================
