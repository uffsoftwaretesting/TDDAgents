PROMPT INICIAL ENVIADO PELO USUARIO
================================================================================
Como engenheiro de software com foco em computação científica, quero desenvolver
uma rotina em Python chamada integracao_trapezio que aproxime o valor de uma
integral definida utilizando a Regra do Trapézio Composta. A função deve ser o
núcleo de um módulo de quadratura numérica de alta performance. Ela deve receber
parâmetros estritamente tipados: a função integranda f(x) como um Callable
nativo do Python, os limites de integração a e b, e o número de subintervalos N
(ou, alternativamente, uma tolerância de erro tolerada para uma abordagem
adaptativa).
