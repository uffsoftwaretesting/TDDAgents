# Especificação Técnica: integracao_simpson_1_3

## 1. Visão Geral do Sistema
Implementar a função `integracao_simpson_1_3` que aproxima valores de integrais definidas sobre `[a, b]` usando a Regra de Simpson 1/3 Composta, garantindo determinismo, clareza, testabilidade e cumprimento estrito dos parâmetros de entrada.

## 2. Estruturas de Dados e Interfaces
Módulo alvo: `src/integration.py`

Assinatura da função:  
```python
def integracao_simpson_1_3(
    f: Callable[[float], float],
    a: float,
    b: float,
    N: int
) -> float:
    """
    Aproxima a integral definida de f sobre [a, b] usando a Regra de Simpson 1/3 Composta.

    Parâmetros:
    - f: função integranda, callable que recebe float e retorna float
    - a: limite inferior de integração (float ou int)
    - b: limite superior de integração (float ou int)
    - N: número de subintervalos, inteiro par e positivo

    Retorna:
    - Aproximação da integral como float
    """
```

Contratos de interface:
- Entrada: apenas os quatro parâmetros acima, sem variáveis globais ou efeitos colaterais.
- Saída: único valor `float`.
- Não usar `print`, `logging`, manipulação de `sys.path` ou variáveis de ambiente.

## 3. Casos de Borda e Validações (Edge Cases)
- **f não é callable**  
  → Lançar TypeError com mensagem clara: `"f deve ser uma função callable que recebe float e retorna float"`.
- **a ou b não é numérico (float/int)**  
  → Lançar TypeError: `"a e b devem ser valores numéricos (float ou int)"`; converter internamente para `float`.
- **N não é int**  
  → Lançar TypeError: `"N deve ser um inteiro par e positivo"`.
- **N ≤ 0 ou N ímpar**  
  → Lançar ValueError: `"N deve ser um inteiro par e maior que zero"`.
- **a > b**  
  → Permitido; calcula normalmente com passo `h = (b - a)/N` (negativo) e retorna valor com sinal apropriado.
- **Funções polinomiais de grau ≤ 3**  
  → Deve retornar valor exato para qualquer `N` par.
- **Funções transcendentes (e.g., sin, exp)**  
  → Deve convergir ao valor de referência dentro de tolerância configurável em testes.
- **N = 0 ou N < 0**  
  → Lançar ValueError: `"N deve ser um inteiro par e maior que zero"`.

- Linguagem-alvo: Python 3.8+  
- Paradigma: funcional, sem estado mutável fora do escopo local.  
- Conformidade PEP8, sem prints ou logs.
