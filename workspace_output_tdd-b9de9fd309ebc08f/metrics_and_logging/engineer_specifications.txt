# Especificação Técnica: Conversor de Numerais Romanos

## 1. Visão Geral do Sistema
Função Python independente que converte uma string representando um numeral romano em seu valor inteiro equivalente (1 a 3999). Valida formato, caracteres, repetições e regras de subtração. Em caso de entrada inválida, lança `ValueError` com mensagem clara. Estruturada para baixíssimo acoplamento e alta coesão, com funções auxiliares para validações e cálculo.

## 2. Estruturas de Dados e Interfaces

### 2.1 Função Principal
Nome: `roman_to_int(roman: str) -> int`  
Parâmetros:  
- `roman` (str): sequência de caracteres romanos.  
Retorno:  
- `int`: valor inteiro correspondente.

### 2.2 Funções Auxiliares
1. `validate_non_empty(roman: str) -> None`  
   - Verifica string não vazia.

2. `validate_characters(roman: str, symbols: Set[str]) -> None`  
   - Garante que todos os caracteres pertençam ao alfabeto romano básico.

3. `validate_repetitions_and_subtractions(roman: str, max_repeats: Dict[str,int], valid_subtractions: Set[str]) -> None`  
   - Limita repetições consecutivas (I,X,C,M ≤ 3; V,L,D ≤ 1).  
   - Rejeita pares subtrativos inválidos.

4. `compute_value(roman: str, values_map: Dict[str,int], valid_subtractions: Set[str]) -> int`  
   - Percorre a string, aplica lógica de subtração quando detecta par válido, soma valores.

### 2.3 Estruturas de Dados Internas
- `values_map: Dict[str,int] = {'I':1,'V':5,'X':10,'L':50,'C':100,'D':500,'M':1000}`
- `valid_subtractions: Set[str] = {'IV','IX','XL','XC','CD','CM'}`
- `max_repeats: Dict[str,int] = {'I':3,'X':3,'C':3,'M':3,'V':1,'L':1,'D':1}`

## 3. Casos de Borda e Validações (Edge Cases)
- Entrada vazia (`''`): lança `ValueError("Input string is empty")`.
- Caracteres não permitidos (ex: `'A'`, `'B'`): `ValueError("Invalid character: A")`.
- Repetição excessiva:
  - Mais de 3 vezes seguidas de I, X, C ou M: ex. `'IIII'`, `'XXXX'`.
  - Qualquer repetição de V, L ou D: ex. `'VV'`, `'LL'`.
- Combinações subtrativas inválidas:
  - Qualquer par não listado em `valid_subtractions` (ex.: `'IC'`, `'IL'`, `'VX'`, `'XM'`, `'IM'`).
- Valor resultante fora do domínio 1–3999:
  - Resultado < 1 ou > 3999 → `ValueError("Result out of range (1–3999): {valor}")`.
- Formatos ambíguos ou incorretos (ex.: `'IIV'`, `'VX'`): encaixam nas regras acima de repetições ou subtrações inválidas.
