# Especificação Técnica: Conversor Fahrenheit para Celsius

## 1. Visão Geral do Sistema
Esta biblioteca fornece uma função para converter temperaturas de Fahrenheit para Celsius, garantindo validação rigorosa de tipo, tratamento explícito de valores especiais de ponto flutuante (NaN e infinito) e precisão adequada usando operações nativas da linguagem.

## 2. Estruturas de Dados e Interfaces

Função pública:
- **Nome**: fahrenheit_to_celsius  
- **Assinatura**:  
  - Parâmetros:
    - `temperature` (int | float): valor da temperatura em Fahrenheit.  
  - Retorno:
    - float: valor correspondente em Celsius, ou NaN/infinito conforme as regras abaixo.  

Contrato de chamada:
- Recebe exatamente um argumento posicional.  
- Se a validação de tipo falhar, levanta `TypeError`.  
- Se o fluxo de execução for bem-sucedido, retorna sempre um `float`.

## 3. Casos de Borda e Validações (Edge Cases)

1. Validação de Tipo de Entrada  
   - Entrada não numérica (ex: str, None, list, dict, objeto customizado):  
     → `TypeError` com mensagem indicando tipo inválido.  

2. Valores Especiais de Ponto Flutuante  
   - `math.isnan(temperature)` é verdadeiro:  
     → retorna `float('nan')`.  
   - `math.isinf(temperature)` é verdadeiro e `temperature > 0`:  
     → retorna `float('inf')`.  
   - `math.isinf(temperature)` é verdadeiro e `temperature < 0`:  
     → retorna `float('-inf')`.  

3. Cálculo para valores finitos  
   - Aplica a fórmula:  
     C = (F − 32) * 5/9  
   - Realiza operações aritméticas nativas garantindo resultado como `float`.  

## 4. Contexto Técnico
- Linguagem-alvo: Python 3.x  
- Paradigma: funcional, sem estados ou efeitos colaterais externos  
- Biblioteca padrão permitida: `math`  
- Precisão: utilizar ponto flutuante IEEE-754 fornecido pelo interpretador  
- Não há persistência, interface de rede ou I/O envolvido  

## 5. Dependências Base (Core Dependencies)
- Python 3.x  
- Biblioteca padrão:  
  - math  
- Framework de testes sugerido:
