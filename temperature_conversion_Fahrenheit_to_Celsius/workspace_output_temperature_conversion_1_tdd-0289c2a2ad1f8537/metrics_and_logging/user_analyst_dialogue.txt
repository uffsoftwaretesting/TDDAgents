[Analista]: Checklist de Requisitos Técnico para a função de conversão Fahrenheit →
            Celsius:

1. Assinatura da Função
1.1. Nome sugerido: fahrenheit_to_celsius(temperature)
1.2. Um único parâmetro: temperature (int ou float)

2. Validação de Tipo de Entrada
2.1. Aceitar apenas valores do tipo int ou float
2.2. Caso contrário, levantar TypeError com mensagem clara (ex: "temperature must be an
int or float")

3. Tratamento de Valores Especiais de Ponto Flutuante
3.1. Importar módulo math da biblioteca padrão
3.2. Se math.isnan(temperature):
• Retornar float('nan')
3.3. Se math.isinf(temperature):
• Retornar math.copysign(float('inf'), temperature)

4. Cálculo da Conversão
4.1. Aplicar fórmula: (temperature - 32) * 5.0 / 9.0
4.2. Garantir que o resultado seja retornado como float

5. Ambiente de Implementação
5.1. Python puro
5.2. Apenas biblioteca padrão (import math)

6. Casos de Teste Necessários
6.1. Casos típicos:
• 32°F → 0.0°C
• 212°F → 100.0°C
• -40°F → -40.0°C
6.2. Valores inteiros diversos:
• 0°F → -17.777…°C
• 100°F → 37.777…°C
6.3. Valores fracionários:
• 98.6°F → 37.0°C (aprox.)
• 45.5°F → 7.5°C (aprox.)
6.4. Valores especiais:
• float('nan') → nan
• float('inf') → inf
• float('-inf') → -inf
6.5. Entrada inválida (levantar TypeError):
• Strings, None, listas, dicionários, objetos personalizados, etc.

7. Não Implementar
7.1. Testes de documentação (docstrings)
7.2. Testes de tipagem estática (mypy, etc.)
