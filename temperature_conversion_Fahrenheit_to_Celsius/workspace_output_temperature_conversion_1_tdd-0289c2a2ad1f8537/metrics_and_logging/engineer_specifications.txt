# Especificação Técnica: Conversor de Temperatura Fahrenheit para Celsius

## 1. Visão Geral do Sistema
O sistema proverá uma única função que converte temperaturas de Fahrenheit para Celsius usando a fórmula C = (F - 32) * 5/9. Deve validar rigorosamente o tipo de entrada, tratar valores especiais de ponto flutuante (NaN e infinito) e retornar sempre um valor float ou levantar erro adequado.

## 2. Estruturas de Dados e Interfaces
- Função pública:
  - Nome: `fahrenheit_to_celsius`
  - Assinatura:  
    - Parâmetro:  
      - `temperature`: int ou float  
    - Retorno:  
      - float  

- Contrato de comportamento:
  1. Se o tipo de `temperature` não for int nem float, levantar `TypeError` com mensagem `"temperature must be an int or float"`.
  2. Se `math.isnan(temperature)` for verdadeiro, retornar `float('nan')`.
  3. Se `math.isinf(temperature)` for verdadeiro, retornar `math.copysign(float('inf'), temperature)`.
  4. Caso contrário, calcular `(temperature - 32) * 5.0 / 9.0` e retornar o resultado como float.

## 3. Casos de Borda e Validações (Edge Cases)
- Validação de tipo:
  - Entrada: `"100"`, `None`, `[]`, `{}`, objeto qualquer → lança `TypeError("temperature must be an int or float")`.
- Valores especiais de ponto flutuante:
  - `float('nan')` → retorna `nan`.
  - `float('inf')` → retorna `inf`.
  - `float('-inf')` → retorna `-inf`.
- Casos típicos:
  - `32` → `0.0`
  - `212` → `100.0`
  - `-40` → `-40.0`
- Valores inteiros diversos:
  - `0` → aproximadamente `-17.77777777777778`
  - `100` → aproximadamente `37.77777777777778`
- Valores fracionários:
  - `98.6` → aproximadamente `37.0`
  - `45.5` → `7.5`

## 4. Contexto Técnico
- Linguagem-alvo: Python 3.x, código imperativo/funções puras.
- Parâgido de execução: ambiente síncrono, sem concorrência.
- Precisão: resultado de ponto flutuante de dupla precisão (IEEE 754).
- Dependência explícita de `import math` para tratamento de NaN, infinito e sinal de infinito.
- Não há persistência, I/O ou configurações externas.
- Não serão implementados testes de documentação nem verificações de tipagem estática em tempo de compilação.
