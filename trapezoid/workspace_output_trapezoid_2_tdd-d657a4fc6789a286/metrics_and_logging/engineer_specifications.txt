# Especificação Técnica: Módulo de Integração Numérica – Regra do Trapézio Composta

## 1. Visão Geral do Sistema
Implementar uma função pura `solve(f, a, b, n)` para aproximar a integral definida de uma função contínua no intervalo \[a, b\] usando a regra do trapézio composta. O objetivo é obter um valor numérico do tipo `float`, de forma determinística, sem efeitos colaterais, obedecendo às boas práticas de Python e sendo passível de testes de convergência numérica.

## 2. Estruturas de Dados e Interfaces
- Localização: arquivo `src/solve.py` contendo apenas a função `solve`.
- Assinatura:
  - `solve(f: Callable[[float], float], a: Union[int, float], b: Union[int, float], n: int) -> float`
- Parâmetros:
  - `f`: função callable que recebe um `float` e retorna um `float`.
  - `a`, `b`: limites de integração, inteiros ou floats, com `a < b`.
  - `n`: número de subintervalos, inteiro positivo (`n ≥ 1`).
- Retorno:
  - Valor da aproximação da integral como `float`.
- Docstring (formato Google ou NumPy):
  - Descrição breve da função.
  - Parâmetros com tipos e significado.
  - Valor de retorno.
  - Exceções levantadas e condições.
- Fluxo de cálculo:
  1. Validar entradas.
  2. Calcular passo `h = (b - a) / n`.
  3. Avaliar `f(x_i)` em cada ponto `x_i = a + i·h`.
  4. Somar pesos: 1 em extremos, 2 em internos.
  5. Multiplicar somatório por `h/2`.
  6. Retornar resultado.

## 3. Casos de Borda e Validações (Edge Cases)
- `f` não é callable  
  - Lança `TypeError("f must be a callable taking one float argument")`
- `a` ou `b` não numéricos (não int/float)  
  - Lança `TypeError("a and b must be int or float")`
- `n` não é int ou `n < 1`  
  - Lança `ValueError("n must be an integer ≥ 1")`
- `a >= b`  
  - Lança `ValueError("a must be less than b")`
- Função `f` lançar exceção em pontos internos ou extremos  
  - Propaga a exceção original para o chamador
- `n = 1`  
  - Caso mínimo: apenas extremos, com `h = b - a`, retorna `(f(a) + f(b)) * h/2`
- Precisão em `n` muito grande  
  - Garantir uso de floats sem arredondamentos indevidos
- Valores de `a` e `b` muito próximos  
  - `h` pequeno mas válido; sem divisão por zero devido à validação `n ≥ 1` e `a < b`

## 4. Contexto Técnico
- Linguagem-alvo: Python 3.8+.
- Paradigma: programação funcional/pura, sem estado global.
- Convenções de estilo: PEP8, type hints, docstrings.
- Determinismo total: sem RNG, sem variáveis globais.
- Execução de testes: padrão `pytest` a partir da raiz do projeto; sem manipulações de `PYTHONPATH` ou `sys.path`.
- Localização do módulo: `src/solve.py`; sem scripts, wrappers ou configurações extras.
- Uso de NumPy: opcional apenas se agregar performance sem complexidade.
