[Analista]: Checklist de Requisitos para adams_bashforth_2 com t_eval e ajuste de h:

1. Validação de Parâmetros
1.1. f deve ser Callable[[float, float], float]. Lançar TypeError se não.
1.2. t0, y0, t_eval e h devem ser floats. Lançar TypeError caso contrário.
1.3. h > 0. Se h <= 0, lançar ValueError.
1.4. t_eval >= t0. Caso contrário, lançar ValueError.

2. Ajuste de h para encaixar em t_eval
2.1. Calcular Δ = t_eval - t0.
2.2. Se Δ == 0: retornar imediatamente y0.
2.3. Calcular n_steps = ceil(Δ / h).
2.4. Recalibrar h = Δ / n_steps.

3. Método de Arranque (Euler Explícito)
3.1. t₁ = t0 + h.
3.2. y₁ = y0 + h * f(t0, y0).

4. Loop Principal (Adams–Bashforth de 2 passos)
Para i de 1 até n_steps-1:
4.1. t_prev = t0 + (i-1)*h, y_prev armazenado.
4.2. t_curr = t0 + i*h, y_curr armazenado.
4.3. y_next = y_curr + h * (1.5 * f(t_curr, y_curr) - 0.5 * f(t_prev, y_prev)).
4.4. Atualizar t_prev=y_curr→y_prev, y_curr=y_next.

5. Saída
5.1. Retornar y_curr (valor escalar no ponto t_eval).

6. Tratamento de Erros em Tempo de Execução
6.1. Capturar e propagar exceções de f.
6.2. Garantir que n_steps não ultrapasse limites de performance ou memória (opcional).

7. Testes Unitários
7.1. ODE linear com solução analítica (por ex. y'=k*y).
7.2. Caso f constante.
7.3. t_eval == t0.
7.4. h exatamente igual a Δ.
7.5. h > Δ.
7.6. h inválido (<=0).
7.7. f não callable.
