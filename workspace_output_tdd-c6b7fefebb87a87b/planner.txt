PLANO DE SUB-REQUISITOS TDD
================================================================================
1. FASE 0 - SETUP AMBIENTE: Configurar o projeto na Cloud Sandbox. Criar virtualenv, instalar pytest e definir estrutura de diretórios: src/adams_bashforth_2.py e tests/test_adams_bashforth_2.py. Incluir pyproject.toml ou setup.cfg com dependências core (typing, math, pytest).
2. FASE 1 - VALIDAÇÃO DE TIPOS E PARÂMETROS: Escrever testes unitários que garantam: f não callable -> TypeError, t0/y0/t_eval/h não float -> TypeError, h<=0 -> ValueError, t_eval<t0 -> ValueError. Criar stubs na função adams_bashforth_2 lançando os erros esperados.
3. FASE 2 - CASO Δ == 0: Escrever teste unitário onde t_eval == t0 e y0 = valor. O teste deve esperar retorno imediato de y0 sem cálculos. Implementar no stub: if Δ==0 return y0.
4. FASE 3 - AJUSTE DE PASSO: Escrever testes para cálculo de Δ = t_eval - t0 > 0, n_steps = ceil(Δ/h) e h_recalibrado = Δ/n_steps. Validar valores de n_steps e h recalculado em cenários distintos. Implementar lógica de ajuste de passo após validações.
5. FASE 4 - PASSO DE ARRANQUE (EULER): Definir teste unitário para um ODE simples (ex: dy/dt = c constante) e validar (t1,y1) após Euler explícito. Na função, calcular t1 = t0 + h, y1 = y0 + h * f(t0, y0).
6. FASE 5 - LOOP ADAMS–BASHFORTH 2 PASSOS: Escrever teste unitário para iteração de vários passos com AB2 usando ODE linear (e.g., dy/dt = λ y). Testar valores intermediários e finais. Implementar loop de i=1 até n_steps-1 aplicando fórmula y_{n+1} = y_n + h*(3/2 f(t_n,y_n) - 1/2 f(t_{n-1},y_{n-1})).
7. FASE 6 - PROPAGAÇÃO DE EXCEÇÕES E LIMITE DE STEPS: Escrever teste que simula f lançando exceção e garante propagação. Opcionalmente, testar cenário de n_steps muito grande e lançar RuntimeError("too many steps"). Implementar passagem de exceções e checagem de limite configurable.
8. FASE 7 - TESTES DE INTEGRAÇÃO E COBERTURA: Escrever testes de integração com casos reais (ex: soluçã o analítica de y'=y, y'=t). Garantir cobertura 100% do módulo, incluindo branches de erro, ajuste de passo, Euler e AB2. Ajustar relatórios pytest.
================================================================================
