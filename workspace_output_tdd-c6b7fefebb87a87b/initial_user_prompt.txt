PROMPT INICIAL ENVIADO PELO USUARIO

uma função em Python chamada adams_bashforth_2 que resolva um Problema de Valor
Inicial (PVI) de uma Equação Diferencial Ordinária (EDO) utilizando o método
explícito de passos múltiplos Adams-Bashforth de 2 passos. A função deve compor
o núcleo de uma biblioteca matemática rigorosamente tipada, recebendo como
parâmetros: a função integranda f(t,y) injetada via Callable nativo puro, as
condições iniciais t0​ e y0​, o tempo limite t_final​ e o tamanho do passo h.
