# Especificação Técnica: Solver de EDO via Adams–Bashforth de 3ª Ordem

## 1. Visão Geral do Sistema
Implementar em Python uma função pura `adams_bashforth_3` que resolve um problema de valor inicial para equações diferenciais ordinárias escalares de primeira ordem, usando o método explícito de Adams–Bashforth de terceira ordem. As duas primeiras etapas são inicializadas com Runge–Kutta de 4ª ordem (RK4). O retorno é unicamente o valor de `y` em `t_final` como `float`, garantindo determinismo, precisão e compatibilidade com sistemas de avaliação automatizada.

## 2. Estruturas de Dados e Interfaces

### 2.1. Tipos e Assinatura
- Definição de tipo:
  - `ODEFunction = Callable[[float, float], float]`
- Assinatura:
  - `adams_bashforth_3(f: ODEFunction, t0: float, y0: float, t_final: float, h: float) -> float`

### 2.2. Interface de Entrada
- `f` : função pura `(t: float, y: float) → dy/dt: float`
- `t0` : instante inicial, `float`
- `y0` : valor inicial em `t0`, `float`
- `t_final` : instante de saída, `float`
- `h` : passo nominal, `float`

### 2.3. Interface de Saída
- `y_final` : estimativa de `y(t_final)`, `float`

### 2.4. Estrutura Interna de Histórico
- Fila deslizante (sliding window) de três tuplas `(t_i, y_i, f_i)`:
  - `(t_{n−2}, y_{n−2}, f_{n−2})`
  - `(t_{n−1}, y_{n−1}, f_{n−1})`
  - `(t_n,       y_n,       f_n)`

## 3. Casos de Borda e Validações (Edge Cases)
- Tipos de Entrada:
  - Se `f` não for chamável: lançar `TypeError`.
  - Se `t0`, `y0`, `t_final` ou `h` não forem `float`: lançar `TypeError`.
- Domínio de Parâmetros:
  - Se `h ≤ 0`: lançar `ValueError("Passo h deve ser > 0")`.
  - Se `t_final < t0`: lançar `ValueError("t_final deve ser ≥ t0")`.
- Construção da Malha:
  - Enquanto `t_current + h < t_final`, usar `dt = h`.
  - No último passo, se `t_current + h ≥ t_final`, definir `dt = t_final − t_current` (pode ser < h).
- Inicialização:
  - Se `t_final − t0 < h`, utilizar RK4 com `dt = t_final − t0` para obter diretamente `y_final`.
- Avaliações de `f`:
  - Se `f` lançar exceção: propagar a exceção sem captura.
  - Se `f` retornar valor não-`float`: lançar `TypeError`.
- Precisão da Malha:
  - Garantir que o último `t_current` seja **exatamente** `t_final`, sem ultrapassar.
- Saída:
  - Nunca retornar listas, arrays ou históricos.
  - Sempre retornar um único `float`.

## 4. Contexto Técnico
- Linguagem-alvo: Python 3.7+.
- Paradigma: imperativo funcional, sem variáveis globais ou estado mutável fora da função.
- Determinismo absoluto: não usar geradores de aleatoriedade ou dependências externas.
- Precisão: mantida em ponto flutuante nativo; não usar bibliotecas de precisão arbitrária.
- Documentação interna: docstring na função explicando assinatura, método RK4 para inicialização e fórmula de AB3.
