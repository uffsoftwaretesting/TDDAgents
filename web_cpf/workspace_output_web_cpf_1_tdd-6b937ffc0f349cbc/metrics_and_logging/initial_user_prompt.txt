PROMPT INICIAL ENVIADO PELO USUARIO
================================================================================
Como desenvolvedor backend experiente, projete e implemente uma API REST
utilizando FastAPI em Python, seguindo rigorosamente os princípios de Clean
Architecture com separação clara de camadas tanto no diretório src quanto em
tests, garantindo baixo acoplamento, alta coesão e uso de injeção de
dependência, sem colocar lógica de negócio nas rotas, organizando o projeto em
domain (regras de negócio e entidades puras), application (casos de uso),
infrastructure (integrações externas como validate-docbr ou python-cpf) e
interfaces ou presentation (controladores FastAPI), com a estrutura de testes
espelhando a de src; o objetivo é expor um endpoint POST /validate-cpf que
receba um JSON com o campo cpf como string e retorne se o CPF é válido ou não
utilizando uma biblioteca confiável, aceitando CPFs com e sem máscara como
123.456.789-09 e 12345678909, validando corretamente dígitos verificadores,
rejeitando CPFs com entradas inválidas, como strings vazias, campos ausentes ou
nulos, caracteres não numéricos inesperados e etc; o contrato da API deve
retornar 200 para requisições válidas com um JSON como { "valid": true } e 422
para payloads inválidos usando validação automática com Pydantic; o
desenvolvimento deve seguir TDD com implementação exclusiva de testes unitários
usando pytest cobrindo todos os cenários relevantes e com estrutura espelhada de
diretórios; além disso, a aplicação deve incluir configuração completa de Docker
para desenvolvimento (com hot reload e volume mount) e produção (com imagem
otimizada e build multi-stage), com Dockerfile e opcionalmente docker-compose, e
um pipeline de CI com GitHub Actions incluindo instalação de dependências,
execução de testes, lint com flake8 e opcionalmente build da imagem, seguindo
boas práticas como tipagem estática, uso de .env, código limpo e suporte à
documentação automática via OpenAPI/Swagger.
================================================================================
