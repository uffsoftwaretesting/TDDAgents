# API de Validação de CPF

Este projeto implementa uma API REST para validação de CPF utilizando Clean Architecture, FastAPI e Pydantic.

## Como executar

- Instalar dependências:

  ```bash
  pip install -r requirements.txt
  ```

- Executar testes:

  ```bash
  pytest
  ```

- Gerar relatório de cobertura:

  ```bash
  pytest --cov=.
  ```

## Linting

Para verificar o estilo do código, utilize o flake8:

```bash
flake8
```
