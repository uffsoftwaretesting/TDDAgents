# Especificação Técnica: derivada_diferenca_central

## 1. Visão Geral do Sistema
A rotina `derivada_diferenca_central` faz parte do núcleo utilitário de uma biblioteca matemática em Python. Seu objetivo é aproximar a primeira derivada de uma função real em um ponto específico usando o método das diferenças finitas centrais de ordem O(h²), garantindo precisão e robustez sem efeitos colaterais.

## 2. Estruturas de Dados e Interfaces

### Assinatura da Função
Nome: `derivada_diferenca_central`  
Parâmetros:
- `f: Callable[[float], float]`  
  – Função matemática pura que mapeia um `float` em outro `float`.  
- `x: float`  
  – Ponto de avaliação da derivada.  
- `h: float`  
  – Passo de perturbação, deve ser positivo.

Retorno:
- `float`  
  – Aproximação da derivada de `f` em `x`.

Imports necessários:
- `from typing import Callable`

### Contrato de Interface
- A função não deve alterar variáveis externas nem manter estado.
- Deve propagar intactas quaisquer exceções geradas em `f(x + h)` ou `f(x - h)`.
- Não faz arredondamento interno; retorna o valor bruto de ponto flutuante.

## 3. Casos de Borda e Validações (Edge Cases)
- Se `f` não for `Callable[[float], float]` → lançar `TypeError("f deve ser Callable[[float], float]")`.
- Se `x` não for `float` → lançar `TypeError("x deve ser float")`.
- Se `h` não for `float` → lançar `TypeError("h deve ser float")`.
- Se `h <= 0` → lançar `ValueError("h deve ser maior que zero")`.
- Se a execução de `f(x + h)` ou `f(x - h)` lançar exceção (ex.: `ZeroDivisionError`, `ValueError`) → propagar sem tratamento.
- Se o cálculo `(f(x + h) - f(x - h)) / (2*h)` resultar em overflow ou `NaN` → retornar conforme especificação IEEE 754, sem interceptação.
- Para funções constantes, espera-se resultado ≈ 0.
- Para funções lineares e quadráticas, verificar convergência à fórmula exata:  
  • Linear \(f(x)=ax+b\) → ≈ a  
  • Quadrática \(f(x)=ax^2+bx+c\) → ≈ 2ax+b  
- Para funções trigonométricas, comparar com `math.cos` e `-math.sin` em pontos apropriados.
- Testar diferentes ordens de grandeza de `h` (10⁻¹ a 10⁻⁸) para validar comportamento O(h²) com tolerância ≤C·h².
