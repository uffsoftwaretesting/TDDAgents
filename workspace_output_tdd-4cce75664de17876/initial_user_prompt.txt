PROMPT INICIAL ENVIADO PELO USUARIO
================================================================================
Como engenheiro de software com foco em computação científica, quero desenvolver
uma rotina em Python chamada derivada_diferenca_central que calcule a primeira
derivada de uma função matemática em um ponto específico utilizando o Método das
Diferenças Finitas Centrais de ordem O(h^2). A função deve compor o núcleo
utilitário de uma biblioteca matemática, recebendo parâmetros estritamente
tipados: a função alvo f(x) como um Callable nativo e puro, o ponto de avaliação
x e o tamanho do passo de perturbação h.
================================================================================
