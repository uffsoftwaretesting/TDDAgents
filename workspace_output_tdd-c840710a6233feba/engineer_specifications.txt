# Especificação Técnica: interpolacao_lagrange

## 1. Visão Geral do Sistema  
O módulo fornece uma rotina `interpolacao_lagrange` em Python que calcula, por meio do Polinômio Interpolador de Lagrange, a aproximação do valor de uma função contínua `f` em um ponto arbitrário `x_alvo`. Destina-se a compor o núcleo de uma biblioteca matemática com tipagem estática rigorosa, garantindo precisão dupla (float64) e tratamento estrito de entradas.

## 2. Estruturas de Dados e Interfaces  
- Assinatura da função:  
  ```python
  def interpolacao_lagrange(
      x_nos: Sequence[float],
      f: Callable[[float], float],
      x_alvo: float
  ) -> float
  ```  
- Parâmetros:  
  - `x_nos`: Sequence[float] — lista ou tupla de pontos de abscissa distintos, tamanho ≥ 1.  
  - `f`: Callable[[float], float] — função nativa pura que, dado `x`, retorna `y = f(x)` como `float`.  
  - `x_alvo`: float — ponto no qual se deseja a avaliação do polinômio.  
- Retorno:  
  - `float` (tipo nativo Python, precisão dupla) com o valor interpolado em `x_alvo`.  
- Exceções documentadas (docstring):  
  - `ValueError` para sequência vazia ou nós duplicados.  
  - `TypeError` para tipos incorretos em `x_nos`, `f(x_i)` ou `x_alvo`.  
- Complexidade: O(n²) em número de operações aritméticas, onde n = len(`x_nos`).  
- Docstring deve conter: parâmetros, retorno, exceções possíveis e complexidade.

## 3. Casos de Borda e Validações (Edge Cases)  
- `x_nos` não é `Sequence` ou `len(x_nos) < 1` → raise ValueError("É necessário pelo menos um nó de abscissa").  
- Algum elemento de `x_nos` não é `float` → raise TypeError("Todos os nós de abscissa devem ser float").  
- `x_alvo` não é `float` → raise TypeError("Ponto alvo deve ser float").  
- Nós duplicados em `x_nos` (∃ i≠j | x_nos[i] == x_nos[j]) → raise ValueError("Nós de abscissa duplicados").  
- `f(x_i)` retorna tipo não-`float` → raise TypeError("Valor de f(x) deve ser float para todos os nós").  
- Caso de único nó (`len(x_nos) == 1`): retorna `f(x_nos[0])` para qualquer `x_alvo`.  
- Extrapolação (`x_alvo` fora de min/max de `x_nos`): cálculo padrão sem erro, retorna valor polinomial.  
- Nenhum retorno silencioso de NaN; todas as falhas de entrada resultam em exceções explícitas.

## 4. Contexto Técnico  
- Linguagem-alvo: Python 3.8+  
- Paradigma: Programação imperativa com tipagem estática via type hints (PEP 484).  
- Precisão numérica: float64 nativo do CPython, sem uso de bibliotecas externas.  
- Ambiente de execução: CPython padrão, sem extensões C ou dependências de álgebra linear.  
- Normas de código: PEP 8 para estilo, PEP 257 para docstrings, complexidade declarada O(n²).

## 5. Dependências Base (Core Dependencies)  
- Python (≥ 3.8), módulo `typing` para `Sequence`, `Callable`.  
- Ferramenta de testes: pytest (padrão-ouro para TDD em Python).  
- Sem outras bibliotecas externas; uso restrito à biblioteca padrão.
