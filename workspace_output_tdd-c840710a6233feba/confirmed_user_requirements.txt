[Analista]: Checklist de Requisitos Técnico para interpolacao_lagrange:

1. Assinatura e Tipagem
- Função com assinatura:
def interpolacao_lagrange(
x_nos: Sequence[float],
f: Callable[[float], float],
x_alvo: float
) -> float
- Todos os floats devem ser do tipo nativo Python (float64).
- Documentar no docstring os tipos de entrada, saída e complexidade O(n²).

2. Validação de Entrada
- Verificar que x_nos é uma Sequence e len(x_nos) >= 1; se não, lançar ValueError.
- Verificar que cada elemento de x_nos é float; caso contrário, lançar TypeError.
- Verificar que x_alvo é float; caso contrário, lançar TypeError.
- Verificar duplicatas em x_nos; se existir x_i == x_j (i≠j), lançar ValueError "Nós de
abscissa duplicados".

3. Geração de Valores y_nos
- Iterar sobre x_nos e chamar f(x_i) para cada x_i.
- Verificar que cada y_i retornado é float; se não for, lançar TypeError.

4. Cálculo do Polinômio de Lagrange
- Para cada i em [0, n-1], calcular o termo:
L_i(x_alvo) = ∏_{j≠i} (x_alvo - x_j) / (x_i - x_j)
- Somar y_i * L_i(x_alvo).
- Executar em precisão dupla (float64) sem bibliotecas externas.

5. Tratamento de Exceções / Casos de Borda
- x_nos vazio → ValueError.
- Tipos inválidos → TypeError.
- Nós duplicados → ValueError.
- Extrapolação (x_alvo fora do intervalo) deve funcionar normalmente.

6. Documentação e Typing
- Incluir docstring detalhando parâmetros, retorno, exceções possíveis e complexidade
algorítmica.
- Incluir type hints para todas variáveis locais e retorno.

7. Testes Unitários (TDD)
- Caso normal: pontos em polinômio de grau 1, 2, 3 (ex: f(x)=ax+b); verificar
aproximação exata.
- Único nó: x_nos=[x0]; qualquer x_alvo → retorno f(x0).
- Extrapolação: x_alvo fora de range → comparar com valor analítico.
- Entrada vazia → espera ValueError.
- Duplicatas em x_nos → espera ValueError.
- f retorna tipo não-float → espera TypeError.
- x_nos ou x_alvo não-float → espera TypeError.
