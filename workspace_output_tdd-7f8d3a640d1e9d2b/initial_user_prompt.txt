PROMPT INICIAL ENVIADO PELO USUARIO
================================================================================
Como engenheiro de software com foco em computação científica, quero desenvolver
uma função em Python chamada rk2_heun que resolva um Problema de Valor Inicial
(PVI) de uma Equação Diferencial Ordinária (EDO) utilizando o método de Runge-
Kutta de 2ª ordem (Heun). A função deve atuar como parte do núcleo de uma
biblioteca matemática de alta performance, exigindo tipagem estática rigorosa
para seus parâmetros: a função da EDO f(t,y) injetada como um Callable nativo
puro, as condições iniciais t0​ e y0​, o tempo final t_final​ e o tamanho do
passo h.
================================================================================
