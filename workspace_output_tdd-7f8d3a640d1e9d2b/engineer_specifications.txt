# Especificação Técnica: rk2_heun

## 1. Visão Geral do Sistema
A função `rk2_heun` implementa o método de Runge-Kutta de 2ª ordem (Heun) para resolver um Problema de Valor Inicial (PVI) de Equação Diferencial Ordinária (EDO) na forma \(y' = f(t,y)\). Dada a condição inicial \((t_0, y_0)\), um passo inicial \(h>0\) e um tempo final \(t_{\text{final}}\ge t_0\), retorna o valor aproximado de \(y(t_{\text{final}})\) em ponto único, ajustando automaticamente o último passo caso não seja múltiplo exato de \(h\).

## 2. Estruturas de Dados e Interfaces
### Assinatura
```python
def rk2_heun(
    f: Callable[[float, float], float],
    t0: float,
    y0: float,
    t_final: float,
    h: float
) -> float
```

### Parâmetros
- **f**: Callable[[float, float], float]  
  Função que calcula a derivada \(\frac{dy}{dt}=f(t,y)\).  
- **t0**: float  
  Tempo inicial.  
- **y0**: float  
  Valor de \(y\) em \(t_0\).  
- **t_final**: float  
  Tempo final de integração (\(\ge t0\)).  
- **h**: float  
  Tamanho de passo inicial (\(>0\)).  

### Retorno
- **y_final**: float  
  Valor aproximado de \(y(t_{\text{final}})\).

### Fluxo Interno
1. Validar tipos e valores de entrada.  
2. Calcular  
   - `n_full = floor((t_final - t0) / h)`  
   - `remainder = (t_final - t0) - n_full * h`  
   - Conjunto de passos: `[h]*n_full` + `[remainder]` se `remainder > 0`.  
3. Iterar sobre cada passo `hi`:
   - `y_pred = y + hi * f(t, y)`  
   - `y_next = y + (hi/2) * (f(t, y) + f(t + hi, y_pred))`  
   - Atualizar `t += hi`, `y = y_next`.  
4. Retornar `y` ao final.

## 3. Casos de Borda e Validações (Edge Cases)
- **f não é Callable**  
  Lança `TypeError("f must be a callable[[float,float], float]")`.
- **t0, y0, t_final ou h não são float**  
  Lança `TypeError("t0, y0, t_final and h must be floats")`.
- **h <= 0**  
  Lança `ValueError("h must be greater than zero")`.
- **t_final < t0**  
  Lança `ValueError("t_final must be greater than or equal to t0")`.
- **t_final == t0**  
  Retorna imediatamente `y0` sem chamar `f`.
- **(t_final – t0)/h não inteiro**  
  Ajusta o último passo para `remainder > 0`. Se `remainder` for muito pequeno (e.g. devido a erros de ponto flutuante), ainda assim realiza um passo final non-zero.
- **f retorna valor não-float**  
  Se possível, converte para `float`; caso contrário, propaga `TypeError`.
- **f lança exceção**  
  Propaga a exceção original sem captura silenciosa.
- **h > (t_final – t0)**  
  `n_full = 0`, único passo de tamanho `remainder = t_final - t0`.
