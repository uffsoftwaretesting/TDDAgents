# Especificação Técnica: rk4_classico

## 1. Visão Geral do Sistema
Implementar em Python uma função pura e determinística que resolva um problema de valor inicial de equação diferencial ordinária escalar de primeira ordem usando o método clássico de Runge-Kutta de quarta ordem (RK4). A função deve receber uma função derivativa `f(t, y)`, condições iniciais `t0`, `y0`, tempo final `t_final` e passo nominal `h`, e retornar somente o valor `y(t_final)` como `float`.

## 2. Estruturas de Dados e Interfaces

Assinatura da função e tipos:
```python
from typing import Callable

def rk4_classico(
    f: Callable[[float, float], float],
    t0: float,
    y0: float,
    t_final: float,
    h: float
) -> float:
    ...
```

Parâmetros:
- `f: Callable[[float, float], float]` – função pura que recebe `(t, y)` e retorna `dy/dt` como `float`.
- `t0: float` – tempo inicial.
- `y0: float` – valor inicial de `y` em `t0`.
- `t_final: float` – tempo final desejado, deve satisfazer `t_final >= t0`.
- `h: float` – passo de integração nominal, deve ser `> 0`.

Retorno:
- `float` – estimativa de `y(t_final)` usando RK4 de ordem 4.

Fluxo interno:
1. Validar entradas.
2. Calcular número de passos inteiros `N = floor((t_final - t0) / h)`.
3. Iterar `i` de `0` a `N-1` com passo fixo `dt = h`.
4. No último passo, usar `dt_last = t_final - t_current` para garantir que `t == t_final`.
5. Em cada iteração, computar:
   ```
   k1 = f(t, y)
   k2 = f(t + dt/2, y + dt*k1/2)
   k3 = f(t + dt/2, y + dt*k2/2)
   k4 = f(t + dt,   y + dt*k3)
   y = y + (dt/6) * (k1 + 2*k2 + 2*k3 + k4)
   t = t + dt
   ```

## 3. Casos de Borda e Validações (Edge Cases)
- **t_final < t0**  
  Lançar `ValueError("t_final must be >= t0")`.
- **h <= 0**  
  Lançar `ValueError("h must be > 0")`.
- **f não é chamável**  
  Lançar `TypeError("f must be callable")`.
- **f retorna tipo não-float**  
  Lançar `TypeError("f must return float")` na primeira chamada que violar isso.
- **t_final == t0**  
  Retornar imediatamente `y0` sem qualquer iteração.
- **(t_final - t0) é múltiplo exato de h**  
  Executar `N = (t_final - t0) / h` iterações com `dt = h`, sem passo truncado.
- **(t_final - t0) não é um múltiplo exato de h**  
  Executar `N = floor((t_final - t0)/h)` iterações com `dt = h` e um passo final `dt_last = t_final - t_current` para alcançar exatamente `t_final`.
- **Acúmulo de erro de ponto flutuante**  
  Garantir que a soma cumulativa dos `dt` nunca ultrapasse `t_final` e atinja exatamente o valor, mesmo em presença de imprecisões de ponto flutuante.
- **f lança exceção**  
  Propagar a exceção sem capturar internamente.

## 4. Contexto Técnico
- Linguagem-alvo: Python 3.8+.
- Paradigma: programação funcional/pura, sem efeitos colaterais.
- Precisão: manter a ordem 4 de convergência do método.
- Retorno estritamente `float`; não usar listas, arrays nem outros históricos.
- Proibir uso de `print()`, `logging` ou variáveis globais.
- Incluir docstring que descreva parâmetros, algoritmo e retorno.
