PLANO DE SUB-REQUISITOS TDD
================================================================================
1. FASE 0 - SETUP: Criar ambiente virtual (venv), instalar pytest e typing (std-lib) via pip; configurar pytest.ini; estruturar diretórios: src/rk4_classico.py e tests/test_rk4_classico.py com arquivos vazios.
2. FASE 1 - VALIDAÇÃO DE TIPOS: Criar testes que assegurem TypeError para f não callable e para cada parâmetro t0, y0, t_final, h que não seja float. Em seguida, implementar essas checagens no início de rk4_classico.
3. FASE 2 - VALIDAÇÃO DE DOMÍNIO: Criar testes que lancem ValueError para h<=0 e para t_final < t0. Implementar verificações correspondentes após as validações de tipo.
4. FASE 3 - CASO TRIVIAL: Criar teste que garante que, se t0 == t_final, a função retorna y0 imediatamente sem loops. Implementar early return y0 nesse cenário.
5. FASE 4 - ESTRUTURA DE LOOP E MALHA: Criar teste para ODE trivial f(t,y)=0 com t_final > t0 e passo h, garantindo que y permanece y0 e não levanta exceção. Implementar inicialização de t, y, while t<t_final: calcular dt=min(h, t_final-t), lançar RuntimeError se dt<=0, atualizar t += dt (mantendo y inalterado).
6. FASE 5 - PASSO ÚNICO RK4: Criar teste para ODE constante f(t,y)=1 com t_final = t0 + h, validando que y retorna exatamente y0 + h. Em code, implementar cálculos k1–k4 e y += (dt/6)*(k1+2*k2+2*k3+k4), atualizar t.
7. FASE 6 - MULTI-STEP RK4: Criar teste para ODE f(t,y)=2*t (solução analítica y=t²) em intervalo [t0,t_final] com múltiplos passos de h, comparando resultado aproximado com valor exato dentro de tolerância. Ajustar loop para várias iterações.
8. FASE 7 - DT FINAL AJUSTADO: Criar teste para garantir que quando (t_final-t0)/h não é inteiro, dt no último passo é <h e y ainda converge corretamente para ODE simples (ex: f(t,y)=1). Verificar funcionamento do min(h, t_final-t).
9. FASE 8 - TIPAGEM E DOCUMENTAÇÃO: Adicionar type hints PEP484 e docstring com descrição de parâmetros, exceções e retorno; configurar mypy no CI e garantir zero erros de tipo; remover quaisquer prints/logging.
