PROMPT INICIAL ENVIADO PELO USUARIO
================================================================================
Como engenheiro de software com foco em computação científica, quero desenvolver
uma função em Python chamada rk4_classico que resolva um Problema de Valor
Inicial (PVI) de uma Equação Diferencial Ordinária (EDO) utilizando o método
clássico de Runge-Kutta de 4ª ordem. A rotina deve ser projetada como o motor
principal de uma biblioteca matemática de alta performance. Os parâmetros devem
ser estritamente tipados: a função da EDO f(t,y) injetada como um Callable
nativo (isento de efeitos colaterais), as condições iniciais t0  ​ e y0​, o
tempo final t_final​ e o tamanho do passo h.
