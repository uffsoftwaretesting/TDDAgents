[Analista]: Checklist de Requisitos Técnico e Testável para integracao_simpson_1_3:

1. Assinatura e Tipagem
1.1. Função: def integracao_simpson_1_3(f: Callable[[float], float], a: float, b: float,
N: int) -> float
1.2. Docstring clara, com descrição de parâmetros, retorno e comportamento em erros.

2. Dependências e Performance
2.1. Uso opcional de NumPy: se importado, gerar vetor de pontos com numpy.linspace e
avaliar f de forma vetorizada.
2.2. Fallback em pure Python caso NumPy não esteja disponível.

3. Validação de Entradas
3.1. Verificar se N é int; se não, lançar TypeError.
3.2. Verificar se N > 0 e par; caso contrário, lançar ValueError("N deve ser um inteiro
par positivo").
3.3. Verificar se a e b são floats ou ints; coagir int para float.

4. Cálculo da Regra de Simpson Composta
4.1. Calcular h = (b - a) / N.
4.2. Gerar pontos x_i: x0 = a, x_N = b; restantes uniformes.
4.3. Calcular f(x0) + f(xN).
4.4. Somar 4 * sum_{i ímpar} f(x_i).
4.5. Somar 2 * sum_{i par, 2 ≤ i ≤ N-2} f(x_i).
4.6. Multiplicar soma total por h/3 e retornar float.

5. Tratamento de Erros em Tempo de Execução
5.1. Se f lançar exceção, propagar.
5.2. Erros de importação (NumPy) não devem impedir execução em pure Python.

6. Casos de Teste (TDD)
6.1. Integral de x^2 de 0 a 1 com N=2 -> resultado ≈ 1/3.
6.2. Integral de sin(x) de 0 a π com N=100 -> resultado ≈ 2.
6.3. N ímpar (ex: N=3) -> ValueError.
6.4. N=0 ou N<0 -> ValueError.
6.5. f que não retorna número -> TypeError ou ValueError.

7. Documentação e Exemplos
7.1. Incluir exemplos de uso no docstring.
7.2. Descrever comportamento quando a == b (pode retornar 0.0).
7.3. Indicar que a > b não é suportado (ou definir política, se desejado).
