# Especificação Técnica: Cálculo de Desconto

## 1. Visão Geral do Sistema  
O sistema fornece uma função para calcular o valor de desconto e o preço final a pagar de um produto, a partir do preço original e de uma porcentagem de desconto. Garante validações de tipo e domínio, aplicação correta da fórmula e arredondamento a duas casas decimais.

## 2. Estruturas de Dados e Interfaces  

### 2.1 Assinatura da Função  
Nome: `calcular_desconto`  
Parâmetros posicionais obrigatórios:  
- `preco` (int ou float)  
- `percentual` (int ou float)  

Retorno:  
- Um dicionário com as chaves:  
  - `"desconto"` → float  
  - `"preco_final"` → float  

### 2.2 Contrato de Entrada  
- `preco`: número inteiro ou de ponto flutuante, valor ≥ 0  
- `percentual`: número inteiro ou de ponto flutuante, 0 ≤ percentual ≤ 100  

### 2.3 Contrato de Saída  
- `"desconto"` = round(preco * (percentual / 100), 2)  
- `"preco_final"` = round(preco − desconto, 2)  

## 3. Casos de Borda e Validações (Edge Cases)  

1. Validações de Tipo  
   - Se `preco` ou `percentual` não forem int nem float → lançar **TypeError** com mensagem  
     “preco e percentual devem ser números (int ou float)”.  

2. Validações de Domínio  
   - `preco < 0` → lançar **ValueError** com mensagem “preco não pode ser negativo”  
   - `percentual < 0` ou `percentual > 100` → lançar **ValueError** com mensagem  
     “percentual deve estar entre 0 e 100”  

3. Cálculo e Arredondamento  
   - Aplica desconto = preco * (percentual / 100), depois arredonda com `round(..., 2)`  
   - Calcula preco_final = preco − desconto, depois arredonda com `round(..., 2)`  

4. Cenários de Teste  
   a) Casos Válidos Básicos  
      - preco=100, percentual=10 → desconto=10.00, preco_final=90.00  
      - preco=250.5, percentual=20 → desconto=50.10, preco_final=200.40  
   b) Casos de Borda  
      - percentual=0 → desconto=0.00, preco_final=preco  
      - percentual=100 → desconto=preco, preco_final=0.00  
   c) Precisão Numérica  
      - preco=99.99, percentual=33.3333 → verificar arredondamento correto (desconto e preco_final com 2 casas)  
   d) Casos Inválidos de Tipo  
      - preco="100" ou preco=None → TypeError  
      - percentual=[10] → TypeError  
   e) Casos Inválidos de Domínio  
      - preco=-1 → ValueError  
      - percentual=-5 ou percentual=150 → ValueError  

## 4. Contexto Técnico  
- Linguagem-alvo: Python 3.x, sem uso de bibliotecas externas além da biblioteca padrão  
- Paradigma: programação funcional/imperativa simples  
- Precisão: arredondamento explícito a duas casas decimais com `round(val, 2)`  
- Não há requisitos de internacionalização ou formatação adicional  

## 5. Dependências Base (Core Dependencies)  
- Python 3.7+  
- Ferramenta de testes: pytest  
- Nenhuma outra dependência externa além da biblioteca padrão do Python
