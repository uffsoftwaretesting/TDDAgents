# Especificação Técnica: Rotina taylor_2

## 1. Visão Geral do Sistema
O objetivo é prover uma função `taylor_2` em Python para resolver Problemas de Valor Inicial (PVI) de Equações Diferenciais Ordinárias (EDO) usando o Método da Série de Taylor de 2ª ordem. A função receberá duas funções puras (primeira e segunda derivada), condições iniciais, passo de integração e tempo final, retornando a aproximação escalar de `y(t_final)`.

## 2. Estruturas de Dados e Interfaces
Função pública:
  `def taylor_2(
       f: Callable[[float, float], float],
       df: Callable[[float, float], float],
       t0: float,
       y0: float,
       t_final: float,
       h: float
   ) -> float`

Parâmetros:
- `f(t, y)`: Callable[[float, float], float] → cálculo de y′.
- `df(t, y)`: Callable[[float, float], float] → cálculo de y′′ (derivada total de f).
- `t0, y0`: valores iniciais de tempo e solução.
- `t_final`: instante final de integração.
- `h`: tamanho de passo inicial (ajustável no último intervalo).

Retorno:
- `float`: valor aproximado de y em `t_final`.

Comportamento (Algoritmo de Taylor 2ª ordem):
1. Calcular `n = floor((t_final - t0)/h)` e resto `r = (t_final - t0) - n*h`.
2. Definir `h_last = r` se `r > 0` (passo final ajustado).
3. Inicializar `t = t0`, `y = y0`.
4. Para cada um dos n passos:
   - `y = y + h*f(t,y) + (h**2/2)*df(t,y)`
   - `t += h`
5. Se `h_last > 0`:
   - `y = y + h_last*f(t,y) + (h_last**2/2)*df(t,y)`
   - `t = t_final`
6. Retornar `y`.

## 3. Casos de Borda e Validações (Edge Cases)

### 3.1 Validações de Parâmetros
- Se `t_final < t0`: lançar `ValueError("t_final deve ser ≥ t0")`.
- Se `t_final == t0`: retornar `y0` imediatamente, sem chamar `f` ou `df`.
- Se `h <= 0` ou `h` for `NaN` ou `Inf`: lançar `ValueError("h deve ser > 0 e finito")`.
- Se `f` ou `df` não forem callables: lançar `TypeError("f e df devem ser callables puros")`.

### 3.2 Ajuste de Passo
- Calcular `n = floor((t_final - t0)/h)`.
- Se resto `r = (t_final - t0) - n*h` for > 0, usar `h_last = r` no último passo.
- Se `r == 0`, não há passo adicional.

### 3.3 Tratamento de Erros em Tempo de Execução
- Se chamadas a `f(t,y)` ou `df(t,y)` lançarem exceções, propagar para o chamador.
- Após cada cálculo de `y`, se for `NaN` ou `Inf`, lançar `RuntimeError("Divergência detectada: valor não finito")`.
