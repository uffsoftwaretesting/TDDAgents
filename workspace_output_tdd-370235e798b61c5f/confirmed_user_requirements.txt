           função integranda f(t,y) (que representa a primeira derivada y′  ), a função
           df(t,y) (que representa a derivada total de f em relação a t, ou seja, y′′),
           as condições iniciais t0​ e y0​, o tempo limite t_final​ e o tamanho do passo
           h. Ambas as funções matemáticas devem ser injetadas como Callable nativos
           estritamente puros.

[Analista]: Checklist de requisitos técnicos para a função taylor_2 (retorno escalar,
            ajuste de h no último passo):

1. Assinatura e Tipagem:
• Definir a função como:
def taylor_2(
f: Callable[[float, float], float],
df: Callable[[float, float], float],
t0: float,
y0: float,
t_final: float,
h: float
) -> float
• Garantir tipagem estática (mypy/pyright)

2. Validação de Parâmetros:
• t_final >= t0; se t_final == t0, retornar y0 imediatamente.
• h > 0 e finito; se inválido, lançar ValueError.
• f e df devem ser callables puros; lançar TypeError se não.

3. Ajuste Automático de Passo (h):
• Calcular n = floor((t_final - t0) / h).
• Se resto r = (t_final - t0) - n*h > 0:
– Ajustar h_last = r para o último passo.
• Durante a iteração, usar h para os primeiros n passos e h_last no passo final.

4. Algoritmo de Série de Taylor de 2ª Ordem:
• Inicializar t = t0, y = y0.
• Para cada passo i de 1 a n:
– y_next = y + h * f(t, y) + (h**2 / 2) * df(t, y)
– t += h; y = y_next.
• Se h_last definido (>0):
– y_final = y + h_last * f(t, y) + (h_last**2 / 2) * df(t, y)
– t = t_final; y = y_final.
• Retornar y (escalar).

5. Tratamento de Erros em Tempo de Execução:
• Capturar e propagar exceptions de f ou df.
• Detectar divergência (NaN, Inf) e lançar RuntimeError.

6. Documentação e Usabilidade:
• Docstring explicando parâmetros, retorno e exceções.
• Exemplo de uso com uma EDO simples.

7. Testes Unitários (TDD):
• Caso trivial y′=0 → y(t)=y0.
• Caso linear y′=a·y (df=a·f) com solução analítica.
• Teste onde (t_final-t0) não é múltiplo de h: verificar h_last.
• Testar limites: t_final==t0, h inválido, f/df não-callable.

8. Qualidade de Código e Ferramentas:
• Linters (flake8), formatador (black).
• Cobertura de testes ≥ 90%.
