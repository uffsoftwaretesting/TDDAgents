PROMPT INICIAL ENVIADO PELO USUARIO
================================================================================
Como engenheiro de software com foco em computação científica, quero desenvolver
uma rotina em Python chamada diferencas_finitas_bvp que resolva um Problema de
Valor de Contorno (BVP) de segunda ordem da forma −u′′ (x)=f(x) utilizando o
Método das Diferenças Finitas. A função deve atuar como o núcleo de uma
biblioteca de simulação espacial, exigindo tipagem estática rigorosa para os
parâmetros: a função fonte f(x) como um Callable nativo vetorizado, o intervalo
de domínio espacial [a,b], um dicionário ou estrutura tipada definindo as
condições de contorno de Dirichlet (u(a) e u(b)), o número de nós internos da
malha N e o ponto específico de avaliação x_alvo.
