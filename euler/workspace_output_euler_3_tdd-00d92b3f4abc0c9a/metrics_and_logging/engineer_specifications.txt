# Especificação Técnica: Solver de EDO com Método de Euler Explícito

## 1. Visão Geral do Sistema
Esta especificação define a função `solve` que realiza a integração numérica de uma equação diferencial ordinária de primeira ordem  
y′ = f(t, y)  
no intervalo [t0, tf] usando o método de Euler explícito uniforme. A saída é o valor aproximado y(tf) em ponto único, sem efeitos colaterais.

## 2. Estruturas de Dados e Interfaces
Função pública:
- **solve(f, t0, tf, y0, n) → float**  
  - Parâmetros:
    - `f`: Callable[[float, float], float]  
      Função RHS da EDO, recebe `(t, y)` e retorna y′.  
    - `t0`: float ou int  
      Tempo inicial.  
    - `tf`: float ou int  
      Tempo final.  
    - `y0`: float ou int  
      Condição inicial y(t0).  
    - `n`: int  
      Número de passos de discretização (deve ser > 0).  
  - Retorno:
    - Valor `y_tf` (float): aproximação de y(tf).

Contrato de comportamento:
- Calcular passo uniforme `h = (tf - t0) / n` (precisão dupla).
- Iterar exatamente `n` vezes:
  1. y ← y + h * f(t, y)  
  2. t ← t + h  
- Retornar y final.

Implementação no módulo:
- Caminho: `src/solve.py`
- Sem scripts auxiliares, wrappers ou manipulação de ambiente.

## 3. Casos de Borda e Validações (Edge Cases)
Validação de entradas:
- `f` não é callable ou não aceita dois argumentos:
  - Elevar `TypeError("f must be a callable accepting (t: float, y: float) and returning float")`.
- `t0`, `tf`, `y0` não numéricos (nem float nem int):
  - Elevar `TypeError("t0, tf, y0 must be numeric (float or int)")`.
- `n` não inteiro ou `n <= 0`:
  - Se tipo inválido: `TypeError("n must be an integer")`.
  - Se ≤ 0: `ValueError("n must be a positive integer")`.

Domínio e limites:
- `tf == t0`:  
  - `h == 0`, loop de Euler não altera `y0`, retorna imediatamente `y0` convertido para float.
- `n` muito grande:
  - Espera-se determinismo; possíveis limitações de desempenho ou precisão inerentes à representação de ponto flutuante.
- Valores de retorno de `f` sendo `inf` ou `nan`:
  - Propagação natural de IEEE754; não há tratamento específico além de documentar que `solve` não intercepta essas condições.

Exceções durante iteração:
- Se `f(t, y)` lançar exceção, interromper imediatamente e propagar o erro.
