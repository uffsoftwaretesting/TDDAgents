# Especificação Técnica: Formatação CEP Brasileiro

## 1. Visão Geral do Sistema
O sistema fornece uma função única, `format_cep`, responsável por receber uma entrada representando um CEP e retornar uma string formatada no padrão brasileiro “XXXXX-XXX”. A função valida rigorosamente o tipo e o conteúdo da entrada, rejeita valores inválidos por meio de exceções claras e garante a formatação correta apenas para sequências de 8 dígitos.

## 2. Estruturas de Dados e Interfaces

### Função pública
- Nome: `format_cep`
- Assinatura:  
  ```python
  def format_cep(cep_input) -> str
  ```
- Parâmetro:
  - `cep_input`: pode ser `str` ou `int`.
- Retorno:
  - `str`: CEP formatado no padrão “XXXXX-XXX” (9 caracteres, incluindo hífen).
- Exceções:
  - `TypeError`: quando `cep_input` não for `str` nem `int`.
  - `ValueError`: quando a sequência resultante contiver caracteres não numéricos ou tiver tamanho diferente de 8.

### Fluxo interno
1. **Validação de tipo**  
   - Se `cep_input` não for instância de (`str`, `int`), lançar TypeError.
2. **Conversão para string**  
   - Se `int`, converter diretamente para `str`.
3. **Validação de conteúdo**  
   - Verificar se todos os caracteres da string são dígitos (0–9).  
   - Se houver qualquer caractere não numérico, lançar `ValueError` com mensagem apropriada.
4. **Validação de tamanho**  
   - Certificar que a string tenha exatamente 8 caracteres.  
   - Caso contrário, lançar `ValueError` com mensagem apropriada.
5. **Formatação**  
   - Inserir um hífen após o quinto dígito:  
     resultado = `digits[:5] + "-" + digits[5:]`

## 3. Casos de Borda e Validações (Edge Cases)

- **Tipo inválido**  
  - Entrada: `None`, `float`, `list`, `dict`, objeto qualquer  
  - Comportamento: lançar `TypeError("Tipo inválido: esperado str ou int.")`
- **Conteúdo não numérico (string)**  
  - Entrada: contém espaços, hífens, letras, símbolos  
    • ex.: `"abcdefgh"`, `"12345-678"`, `" 12345678 "`  
  - Comportamento: lançar `ValueError("CEP deve conter apenas dígitos.")`
- **Quantidade de dígitos diferente de 8**  
  - Entrada: sequência limpa com menos de 8 ou mais de 8 dígitos  
    • ex.: `"1234"`, `"123456789"`  
  - Comportamento: lançar `ValueError("CEP deve ter exatamente 8 dígitos.")`
- **Zeros à esquerda**  
  - Entrada: `"00000001"`, `1_234` convertido em `"00001234"` (se for exatamente 8 caracteres)  
  - Comportamento: formatar normalmente → `"00000-001"`, `"00001-234"`
- **Casos válidos**  
  - format_cep("24350310") → "24350-310"  
  - format_cep(12345678)    → "12345-678"  
  - format_cep("00000001") → "00000-001"

## 4. Contexto Técnico
- Linguagem-alvo: Python 3.x (puro, apenas biblioteca padrão).  
- Paradigma: função pura sem efeitos colaterais.  
- Não usar regex nem bibliotecas de terceiros.  
- Estilo de exceções e mensagens deve ser consistente e em português.  
- Foco em TDD: a especificação de tipos, limites e mensagens será a única fonte de verdade para a suíte de testes.
