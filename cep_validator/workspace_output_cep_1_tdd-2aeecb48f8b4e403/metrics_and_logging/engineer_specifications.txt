# Especificação Técnica: Formatador de CEP

## 1. Visão Geral do Sistema
O sistema provê uma única função `format_cep` para normalizar e formatar sequências que representam CEPs brasileiros no padrão “XXXXX-XXX”. Deve aceitar entradas do tipo `str` ou `int`, validar rigorosamente tipo e conteúdo, e retornar uma string formatada com hífen após o quinto dígito.

## 2. Estruturas de Dados e Interfaces
Interface pública:
- Assinatura:  
  def format_cep(cep) -> str

Entradas:
- `cep` (str ou int): valor que representa exatamente oito dígitos de um CEP.

Saída:
- Retorna `str` formatado como `XXXXX-XXX`.

Contrato e pré-condições:
1. Se `cep` não for `str` nem `int`, interromper com `TypeError`.
2. Converter inteiro em string (`str(cep)`).
3. Após conversão, a string deve conter apenas caracteres dígito (`0-9`).
4. O comprimento da string deve ser exatamente 8.
5. Se alguma regra acima falhar, lançar exceções apropriadas com mensagens descritivas.
6. Em caso de sucesso, inserir hífen entre o quinto e o sexto dígitos e retornar.

Exceções e mensagens esperadas:
- TypeError("CEP deve ser uma string ou inteiro")
- ValueError("CEP deve conter apenas dígitos")
- ValueError("CEP deve ter exatamente 8 dígitos")

## 3. Casos de Borda e Validações (Edge Cases)
1. **Tipo Inválido (TypeError)**
   - Entrada `None` → TypeError
   - Entrada `12.345678` (float) → TypeError
   - Entrada objeto genérico (`object()`) → TypeError
2. **Conteúdo Não Numérico (ValueError)**
   - `"abcdefgh"` → ValueError
   - `" 12345678 "` (espaços) → ValueError
3. **Quantidade de Dígitos Incorreta (ValueError)**
   - `"1234"` (4 dígitos) → ValueError
   - `"123456789"` (9 dígitos) → ValueError
   - `1234` (inteiro com menos dígitos) → ValueError
   - `123456789` (inteiro com mais dígitos) → ValueError
4. **Sinal Negativo em Inteiro (ValueError)**
   - `-12345678` → ValueError (após conversão string contém '-')
5. **Casos Válidos**
   - `"24350310"` → retorna `"24350-310"`
   - `12345678` → retorna `"12345-678"`
   - `"00000000"` → retorna `"00000-000"`
6. **Casos de Borda de Formatação**
   - CEPs com zeros à esquerda preservados (`"00123456" -> "00123-456"`)

## 4. Contexto Técnico
- Linguagem-alvo: Python 3.x (versões modernas, ≥3.6).
- Paradigma: imperativo funcional, código linear e legível.
- Ambiente: puro Python, sem dependências externas além da biblioteca padrão.
- Exceções devem interromper imediatamente o fluxo de execução.
- Mensagens de erro claras e em português.
- Não requer persistência, I/O ou multithreading.

## 5. Dependências Base (Core Dependencies)
- Runtime: Python 3.6+  
- Testes: pytest (framework de testes)  
- Biblioteca padrão do Python (str, exceptions)
