   formatar códigos de CEP no padrão brasileiro. A tarefa é projetar e implementar, em
   Python puro e sem uso de bibliotecas externas além da biblioteca padrão, uma função
   que receba como entrada uma sequência representando um CEP e retorne uma string
   formatada no padrão “XXXXX-XXX”. A saída deve ser uma string contendo exatamente oito
   dígitos com inserção automática de hífen após o quinto dígito. O método deve validar
   e normalizar a entrada garantindo que apenas dígitos sejam considerados, podendo
   aceitar tanto strings quanto inteiros desde que representem exatamente 8 dígitos, e
   então aplicar a formatação por meio de manipulação de strings. As premissas incluem
   validação rigorosa de tipos e conteúdo, rejeitando entradas inválidas como strings

   mensagens claras. Os testes devem incluir casos válidos (por exemplo, "24350310" →
   "24350-310", 12345678 → "12345-678"), casos inválidos (como "1234", "abcdefgh",
   "123456789", None) e casos de borda (como entradas com zeros à esquerda). Não devem
   ser implementados testes de documentação, docstrings ou types.

[Analista]: Checklist de Requisitos Técnico para a função format_cep(input_ceps):

1. Definição da Interface
• Assinatura: def format_cep(cep)
• Entrada aceita: str ou int
• Saída: str no formato “XXXXX-XXX”

2. Validação de Tipo
• Se tipo de `cep` não for str nem int: lançar TypeError(
mensagem clara, ex: “CEP deve ser uma string ou inteiro”
)

3. Normalização e Validação de Conteúdo
• Converter int para str: cep_str = str(cep)
• Verificar se cep_str contém apenas dígitos (`str.isdigit()`):
– Caso contrário: lançar ValueError(“CEP deve conter apenas dígitos”)
• Verificar comprimento exato de 8 caracteres:
– Se len(cep_str) != 8: lançar ValueError(“CEP deve ter exatamente 8 dígitos”)

4. Formatação
• Inserir hífen após o quinto dígito:
formatted = cep_str[:5] + '-' + cep_str[5:]
• Retornar formatted

5. Tratamento de Casos de Erro
• Entradas inválidas devem interromper a execução e lançar a exceção apropriada
• Mensagens de erro devem ser descritivas

6. Testes Automatizados (TDD)
a) Casos Válidos
• format_cep("24350310") → "24350-310"
• format_cep(12345678) → "12345-678"
• format_cep("00000000") → "00000-000"
b) Casos Inválidos (ValueError)
• format_cep("1234")
• format_cep("abcdefgh")
• format_cep("123456789")
• format_cep(1234)
• format_cep(123456789)
• format_cep(" 12345678 ")
• format_cep(-12345678)
c) Casos de Tipo Inválido (TypeError)
• format_cep(None)
• format_cep(12.345678)
• format_cep(object())

7. Não Funcionais
• Implementação em Python puro (somente biblioteca padrão)
• Uso de operações de string e checagens internas
• Código simples, legível e fácil de manter
