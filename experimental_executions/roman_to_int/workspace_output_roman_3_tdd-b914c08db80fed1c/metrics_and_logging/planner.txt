PLANO DE SUB-REQUISITOS TDD
================================================================================
1. FASE 0 - SETUP: Criar um virtualenv Python 3.x, instalar pytest (pip install pytest), estruturar diretórios src/ e tests/, criar arquivos vazios src/roman.py e tests/test_roman.py e configurar pytest.ini
2. FASE 1 - VALIDAÇÃO DE TIPO: Escrever testes unitários (pytest) em tests/test_roman.py que chamem roman_to_int com inputs não-str (None, 123, []) e esperem TypeError; executar para vermelhar
3. FASE 2 - NORMALIZAÇÃO: Adicionar teste para entrada lowercase (ex.: 'mcmxciv' → 1994) esperando sucesso; implementar roman = roman.upper() antes de qualquer validação
4. FASE 3 - STRING VAZIA: Escrever teste que invoque roman_to_int('') e espera ValueError; implementar verificação len(roman) > 0 e lançar ValueError caso vazio
5. FASE 4 - VALIDAÇÃO DE CARACTERES: Criar testes para inputs com caracteres inválidos (ex.: 'A', 'B1') esperando ValueError; implementar checagem de cada símbolo estar em ROMAN_VALUES
6. FASE 5 - REGRAS DE REPETIÇÃO: Escrever testes para repetições ilegais (ex.: 'IIII','XXXX','VV') aguardando ValueError; implementar lógica que conte repetições consecutivas conforme regras do domínio
7. FASE 6 - REGRAS DE SUBTRAÇÃO: Adicionar testes para pares válidos (IV, IX, XL, XC, CD, CM) e inválidos (IIV, IL, IC); esperar ValueError nos inválidos; implementar validação de pares usando VALID_SUBTRACTIVE_PAIRS
8. FASE 7 - PARSING E SOMA/SUBTRAÇÃO: Escrever testes para conversão de casos simples ('III'→3,'LVIII'→58) e compostos ('MCMXCIV'→1994); implementar loop de parsing que compara valor atual com o próximo e soma/subtrai conforme regras
9. FASE 8 - VERIFICAÇÃO DE FAIXA: Criar testes para resultado fora de domínio (ex.: 'MMMM'→4000) esperando ValueError e para borda ('I'→1,'MMMCMXCIX'→3999) retornando o valor correto; implementar checagem do resultado final em [MIN_VALUE,MAX_VALUE]
10. FASE 9 - INTEGRAÇÃO FINAL: Consolidar testes de todos os exemplos válidos e inválidos da especificação, garantir cobertura completa, e executar pytest para validar fluxo end-to-end
11. FASE 10 - CI E LINT (OPCIONAL): Configurar lint (flake8/mypy), adicionar comando pytest no pipeline de CI e assegurar qualidade de código antes do merge
================================================================================
