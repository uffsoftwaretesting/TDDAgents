# Especificação Técnica: Integração Simpson 1/3 Composta

## 1. Visão Geral do Sistema
Esta especificação define a função `integracao_simpson_1_3`, responsável por aproximar o valor de uma integral definida no intervalo [a, b] utilizando a Regra de Simpson 1/3 Composta. O objetivo é obter uma implementação em Python que seja clara, determinística, livre de efeitos colaterais e adequada à validação automática de testes de convergência numérica.

## 2. Estruturas de Dados e Interfaces

### 2.1 Módulo e Localização
- Arquivo: `src/integracao.py`
- Módulo público: nenhuma classe exposta, apenas a função descrita abaixo.

### 2.2 Função Pública

#### `integracao_simpson_1_3`
- Assinatura  
  ```python
  def integracao_simpson_1_3(
      f: Callable[[float], float],
      a: float,
      b: float,
      N: int
  ) -> float
  ```
- Parâmetros  
  - `f`: função integranda, chamável, que recebe um `float` e retorna um `float`.  
  - `a`, `b`: limites de integração, `float` ou `int` conversível para `float`.  
  - `N`: número de subintervalos, inteiro par positivo.

- Retorno  
  - Valor aproximado da integral definida de `f(x)` em `[a, b]`, como `float`.

- Exceções  
  - `TypeError` se `f` não for chamável.  
  - `TypeError` se `a` ou `b` não forem números (não `int`/`float`).  
  - `ValueError` se `N` não for inteiro, não for positivo ou não for par.  

- Docstring  
  Deve conter descrição breve, parâmetros, valor de retorno e exceções lançadas.

### 2.3 Contratos de Integração
- Não há comunicação via rede ou IO: a função trabalha apenas com parâmetros e retorno.  
- Não há uso de variáveis globais ou estado externo.  

## 3. Casos de Borda e Validações (Edge Cases)

- **f não é chamável**  
  - Entrada: `f = 42`  
  - Comportamento: lançar `TypeError("f must be callable")`.

- **a ou b não numéricos**  
  - Entrada: `a = "0"`, `b = 1.0`  
  - Comportamento: lançar `TypeError("a and b must be numbers")`.

- **N não inteiro**  
  - Entrada: `N = 3.5`  
  - Comportamento: lançar `ValueError("N must be an integer")`.

- **N não positivo**  
  - Entrada: `N = 0` ou `N < 0`  
  - Comportamento: lançar `ValueError("N must be positive and even")`.

- **N não par**  
  - Entrada: `N = 3, 5, ...`  
  - Comportamento: lançar `ValueError("N must be positive and even")`.

- **a == b**  
  - Definição: intervalo de amplitude zero.  
  - Comportamento: retornar `0.0` (integral nula).

- **a > b**  
  - Inversão de limites: calcular integral em `[b, a]` e retornar com sinal invertido.

- **Função f lança exceção em algum ponto interno**  
  - Propagação da exceção sem captura genérica.
