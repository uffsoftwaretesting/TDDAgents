# Especificação Técnica: Integrador com Regra de Simpson 1/3 Composta

## 1. Visão Geral do Sistema
Implementação de uma função em Python que aproxima o valor de uma integral definida pela Regra de Simpson 1/3 Composta de forma determinística, eficiente e testável. O sistema recebe uma função integranda, limites de integração e número de subintervalos pares, e retorna o valor aproximado da integral sem efeitos colaterais.

## 2. Estruturas de Dados e Interfaces

Função pública:

```python
def integracao_simpson_1_3(
    f: Callable[[float], float],
    a: float,
    b: float,
    N: int
) -> float
```

Parâmetros:
- f: Callable[[float], float]  
  Função que recebe um valor float x e retorna f(x) como float.  
- a: float  
  Limite inferior de integração.  
- b: float  
  Limite superior de integração.  
- N: int  
  Número de subintervalos (deve ser par e maior que zero).

Retorno:
- float  
  Valor aproximado da integral de f no intervalo \[a, b\] pela Regra de Simpson 1/3 Composta.

Docstring deve descrever:
- Objetivo da função.
- Tipos e significados de cada parâmetro.
- Tipo e precisão do valor retornado.
- Exceções levantadas em casos de validação de entrada.

## 3. Casos de Borda e Validações (Edge Cases)
- f não é callable  
  • Exceção: TypeError com mensagem descritiva.  
- a ou b não são valores numéricos (float ou int)  
  • Exceção: TypeError com mensagem descritiva.  
- N não é inteiro ou N ≤ 0  
  • Exceção: ValueError com mensagem “N deve ser inteiro par e maior que zero.”  
- N é inteiro mas ímpar  
  • Exceção: ValueError com mensagem “N deve ser par.”  
- a == b  
  • Retorno imediato de 0.0 sem erro.  
- Domínio de f fora de limites previstos por usuário  
  • Propagar exceção de f sem captura adicional (fail-fast).  
- Precisão e determinismo  
  • Chamadas repetidas com mesmos argumentos devem retornar exatamente mesmo float (sem ruído).
