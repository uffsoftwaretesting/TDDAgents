# Especificação Técnica: adams_bashforth_3

## 1. Visão Geral do Sistema
A função `adams_bashforth_3` resolve numericamente um problema de valor inicial para EDO escalar de primeira ordem  
dy/dt = f(t, y) usando o método explícito de Adams–Bashforth de 3ª ordem. Os dois primeiros passos são inicializados  
via Runge–Kutta de 4ª ordem (RK4). A malha temporal é ajustada para que o último ponto coincida exatamente com `t_final`.  
O retorno é apenas o valor escalar `y(t_final)`.

## 2. Estruturas de Dados e Interfaces

### Interface pública
```
def adams_bashforth_3(
    f: Callable[[float, float], float],
    t0: float,
    y0: float,
    t_final: float,
    h: float
) -> float
```

- `f`: função pura de assinatura f(t: float, y: float) → float, sem efeitos colaterais.  
- `t0`: tempo inicial (float).  
- `y0`: condição inicial y(t0) (float).  
- `t_final`: tempo final de integração (float).  
- `h`: passo nominal de integração (float).  
- Retorna: estimativa `y(t_final)` (float).

### Contratos internos
- Tipos: todos os parâmetros e o retorno são `float`.  
- Passo deliberado: em cada iteração, usa-se um `dt`, igual a `h` salvo para o último passo, que pode ser menor.  
- Histórico de estados: mantém três triplas (t, y, f(t,y)) para aplicação do AB3.

## 3. Casos de Borda e Validações (Edge Cases)
- Validações iniciais (lançar TypeError/ValueError antes de qualquer cálculo):
  - Se `f` não for callable → TypeError.  
  - Se qualquer um de `t0, y0, t_final, h` não for float → TypeError.  
  - Se `h <= 0` → ValueError.  
  - Se `t_final < t0` → ValueError.
- Caso trivial `t_final == t0`: retorna imediatamente `y0`.
- Intervalo total `Δ = t_final - t0`:
  - Se `Δ < h`:  
    • Um único passo via RK4 com `dt = Δ`; retorna valor RK4.  
  - Se `h ≤ Δ < 2h`:  
    • Primeiro passo RK4 com `dt = h` → y1.  
    • Segundo passo RK4 com `dt = Δ - h` → y2; retorna y2.  
- Para `Δ ≥ 2h`:  
  - Inicialização via RK4 com dois passos de tamanho `h` para obter y1 e y2.  
  - Em seguida, para n = 2 até N = floor(Δ/h):
    • Usa-se fórmula AB3 com `dt = h`, salvo no último passo, se `Δ - N*h > 0`, ajuste `dt = Δ - N*h`.
    • Atualiza histórico descartando o estado mais antigo.
- Precisão do último ponto: garante t_n + dt == t_final, sem ultrapassar.

## 4. Contexto Técnico
- Linguagem: Python 3.x.  
- Paradigma: procedimental, determinístico, sem variáveis globais ou aleatórias.  
- Ponto flutuante: todas as operações seguem ordem fixa para garantir repetibilidade de resultados.  
- A função não retorna arrays nem históricos, apenas o valor escalar final.
