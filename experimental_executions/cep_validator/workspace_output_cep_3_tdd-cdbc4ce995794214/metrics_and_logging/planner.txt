================================================================================
1. FASE 0 - SETUP: Criar virtualenv com Python 3.6+, instalar pytest, configurar pyproject.toml com seção [tool.pytest] e [tool.coverage]; estruturar diretórios: src/cep_formatter/formatter.py (arquivo vazio) e tests/test_formatter.py (arquivo vazio).
2. FASE 1 - NÚCLEO LÓGICO (Happy Path): No tests/test_formatter.py, escrever teste para format_cep('12345678') → '12345-678'; executar pytest (deve falhar); implementar em src/cep_formatter/formatter.py função format_cep que recebe string, fatiando e concatenando hífen para passar o teste.
3. FASE 2 - VALIDAÇÃO DE TIPO: Adicionar testes parametrizados em tests/test_formatter.py para entradas [None, 12.345678, [], {}] e assert_raise TypeError('CEP deve ser string ou inteiro'); executar pytest (falha); estender format_cep para validar isinstance(cep, (str, int)) e lançar TypeError com mensagem exata.
4. FASE 3 - VALIDAÇÃO DE DÍGITOS: Adicionar testes para entradas ['abcdefgh', '12.345-678', -12345678] esperando ValueError('CEP deve conter apenas dígitos'); executar pytest (falha); converter int para str, usar cep_str.isdigit() e lançar ValueError com mensagem exata quando falhar.
5. FASE 4 - VALIDAÇÃO DE COMPRIMENTO: Adicionar testes parametrizados para entradas ['1234', 1234, '123456789', 123456789] esperando ValueError('CEP deve ter exatamente 8 dígitos'); executar pytest (falha); implementar checagem len(cep_str)==8 e lançar ValueError com mensagem exata quando diferente de 8.
6. FASE 5 - NORMALIZAÇÃO E CASOS EXTRAS: Adicionar testes para entradas ['00000000', 10000000] e validar retornos '00000-000' e '10000-000'; executar pytest e ajustar formatação para preservar zeros à esquerda e tratar inteiros corretamente.
7. FASE 6 - DOCUMENTAÇÃO E COVERAGE: Inserir docstring de formato padrão (param, return, raises) em format_cep; configurar pytest-cov para atingir 100% de coverage em src/cep_formatter/formatter.py; gerar badge de CI e verificar pipelines de testes passam sem erros.
