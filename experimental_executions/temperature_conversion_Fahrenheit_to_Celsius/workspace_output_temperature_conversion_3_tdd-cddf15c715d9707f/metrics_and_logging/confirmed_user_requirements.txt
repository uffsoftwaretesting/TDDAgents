REQUISITOS ENVIADOS PELO USUÁRIO
================================================================================
[Usuário]: Aja como um engenheiro de software especializado em Python. O caso de uso
           consiste em converter temperaturas de Fahrenheit para Celsius. A tarefa é
           projetar e implementar, em Python puro e sem uso de bibliotecas externas além
           da biblioteca padrão, uma função que receba um número real (int ou float)
           representando a temperatura em Fahrenheit. A saída deve ser um número real
           correspondente em Celsius, calculado pela fórmula C = (F - 32) * 5/9. Tratar
           explicitamente valores especiais de ponto flutuante como NaN e infinito. As
           premissas incluem validação rigorosa de tipos, rejeitando entradas não
           numéricas (como strings, None ou objetos) com TypeError. Os testes devem
           incluir casos típicos, valores negativos, valores fracionários e casos
           especiais (NaN, infinito). Não devem ser implementados testes de
           documentação, docstrings ou types.
[Analista]: Checklist de Requisitos Técnico para a função de conversão Fahrenheit →
            Celsius:

1. Assinatura da Função
• Definir função pura, sem efeitos colaterais, por exemplo:
def fahrenheit_to_celsius(fahrenheit):
• Receber um único parâmetro “fahrenheit”.

2. Validação de Tipo
• Aceitar apenas int ou float.
• Se o tipo for diferente, lançar TypeError com mensagem clara (ex: "fahrenheit must be
int or float").

3. Tratamento de Valores Especiais de Float
• Se fahrenheit for NaN, retornar NaN (math.isnan ou float('nan')).
• Se fahrenheit for +inf ou -inf, retornar +inf ou -inf respectivamente.

4. Cálculo da Conversão
• Aplicar a fórmula: C = (F − 32) * 5.0/9.0.
• Garantir divisão em ponto flutuante (usar 5.0/9.0 ou float()).

5. Value Return
• Retornar sempre um float.

6. Cobertura de Testes (Testes Unitários)
6.1 Casos Típicos
– 32 → 0.0
– 212 → 100.0
6.2 Valores Negativos
– -40 → -40.0
– -58 → -50.0
6.3 Valores Fracionários
– 98.6 → 37.0 (aproximação exata)
– 0.5 → -17.5
6.4 Casos Especiais de Float
– NaN → NaN
– +inf → +inf
– -inf → -inf
6.5 Erro de Tipo
– Chamar com None, "123", [], {} → TypeError

7. Não implementar testes de documentação (docstrings) nem verificação de tipos via
decorators ou libs externas.
