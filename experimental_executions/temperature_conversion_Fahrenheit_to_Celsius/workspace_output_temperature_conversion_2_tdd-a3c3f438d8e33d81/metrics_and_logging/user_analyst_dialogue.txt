[Analista]: Checklist de Requisitos para função fahrenheit_to_celsius:

1. Validação de Tipo de Entrada
- A função deve aceitar apenas valores do tipo int ou float.
- Se a entrada não for int nem float (ex: str, None, list, dict, objeto customizado),
deve levantar TypeError.

2. Tratamento de Valores Especiais de Ponto Flutuante
- Se o valor for NaN (math.isnan), a função deve retornar NaN.
- Se o valor for +infinito (math.isinf e valor > 0), retornar +infinito.
- Se o valor for -infinito (math.isinf e valor < 0), retornar -infinito.

3. Cálculo da Conversão
- Aplicar a fórmula C = (F - 32) * 5/9.
- Garantir precisão adequada de ponto flutuante usando operações nativas.
- O resultado deve ser retornado como float.

4. Casos de Teste a Implementar
a) Valores Típicos:
- 32°F → 0°C
- 212°F → 100°C
b) Valores Negativos:
- -40°F → -40°C
- -4°F → aproximadamente -20°C
c) Valores Fracionários:
- 98.6°F → aproximadamente 37°C
- 0.5°F → aproximadamente -17.5°C
d) Valores Especiais:
- math.nan → math.nan
- math.inf → math.inf
- -math.inf → -math.inf
e) Entradas Inválidas (esperar TypeError):
- "100"
- None
- []
- {}
- objeto customizado sem sobrecarga numérica

5. Não implementar testes de docstrings nem validação de anotações de tipo.
