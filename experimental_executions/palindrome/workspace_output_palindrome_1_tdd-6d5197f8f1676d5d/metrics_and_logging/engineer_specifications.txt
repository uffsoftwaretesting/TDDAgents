# Especificação Técnica: Verificador de Palíndromos

## 1. Visão Geral do Sistema
O sistema oferece uma única função, `is_palindrome(s)`, que verifica se uma string é palíndroma após normalização. A normalização inclui remoção de caracteres não alfanuméricos, remoção de espaços, e conversão para minúsculas, garantindo case-insensitivity. A complexidade de tempo é linear (O(n)).

## 2. Estruturas de Dados e Interfaces

### 2.1 Função Pública
- **Assinatura**  
  `def is_palindrome(s) -> bool`
- **Parâmetros**  
  - `s`: instância de `str`.  
- **Retorno**  
  - `True` se, após normalização, `s` for palíndroma.  
  - `False` caso contrário.  
- **Exceções**  
  - Lança `TypeError` se `s` não for `str`. Mensagem:  
    `"Input must be a string, got <tipo_recebido>"`

### 2.2 Normalização Interna
- **Remoção de não-alfanuméricos**: descartar todos os caracteres que não atendem ao padrão `[A-Za-z0-9]`.  
- **Ignorar espaços**: espaços são removidos no mesmo passo da filtragem.  
- **Case-insensitive**: converter cada caractere alfanumérico para minúsculo.  
- **Representação intermediária**: string resultante contendo apenas caracteres lowercase e alfanuméricos.

### 2.3 Lógica de Verificação
- Utilizar dois ponteiros `i` (início) e `j` (fim) na string normalizada.  
- Iterar enquanto `i < j`:
  - Comparar `normalized[i]` com `normalized[j]`.  
  - Se diferirem, retornar `False`.  
  - Caso igual, incrementar `i` e decrementar `j`.  
- Se todos os pares conferirem, retornar `True`.

## 3. Casos de Borda e Validações (Edge Cases)
- **Tipo inválido**  
  - `None`, `int`, `float`, `list`, `dict`, qualquer outro não-`str` → `TypeError("Input must be a string, got <tipo>")`.
- **String vazia (`""`)**  
  - Normalizada permanece vazia → retorna `True`.
- **String com único caractere**  
  - Exemplo: `"a"`, `"Z"`, `"$"`. Após normalização pode ficar vazio ou ter 1 char → retorna `True`.
- **String com apenas não-alfanuméricos**  
  - Exemplo: `"!!!***"`. Normalizada fica vazia → retorna `True`.
- **Strings com caracteres alfanuméricos misturados e pontuação**  
  - Normalização válida mesmo em casos extremos (ex.: muitos símbolos entre letras).
- **Valores fora do domínio esperado (ex.: desempenho)**  
  - A implementação não deve exceder O(n) tempo ou alocar além de O(n) memória proporcional ao comprimento de `s`.

## 4. Contexto Técnico
- Linguagem-alvo: **Python 3.8+**, estilo imperativo e funcional mínimo.  
- Proibição de bibliotecas externas: usar apenas módulos da biblioteca padrão.  
- Paradigma: função pura (sem efeitos colaterais).  
- Critérios de performance:  
  - Tempo: O(n), onde n = tamanho de `s`.  
  - Espaço adicional: O(n) para string normalizada; não usar estruturas extras desnecessárias.
