REQUISITOS ENVIADOS PELO USUÁRIO
================================================================================
[Usuário]: Aja como um engenheiro de software especializado em Python. O caso de uso
           consiste em verificar se uma string representa um palíndromo. A tarefa é
           projetar e implementar, em Python puro e sem uso de bibliotecas externas, uma
           função que receba uma string como entrada e retorne um valor booleano, sendo
           True para palíndromos e False caso contrário. A saída deve refletir
           corretamente a verificação após normalização da entrada. O método deve tornar
           a verificação case-insensitive, remover espaços em branco, ignorar pontuação
           e caracteres não alfanuméricos, e operar com complexidade O(n). As premissas
           incluem validação rigorosa de tipos, lançando TypeError para entradas
           inválidas como None, números ou outros objetos, e tratamento de comportamento
           para casos de borda como string vazia e strings com um único caractere. Os
           testes devem incluir casos válidos, casos não palíndromos, e casos de borda
           (string vazia e um único caractere). Não devem ser implementados testes de
           documentação, docstrings ou types.
[Analista]: Checklist de Requisitos para Função Verificadora de Palíndromos em Python:

1. Assinatura da Função:
- Definir função `is_palindrome(s: str) -> bool` que receba exatamente um parâmetro `s`
do tipo `str`.

2. Validação de Tipo:
- Se `s` não for instância de `str`, lançar `TypeError` com mensagem clara (ex: “Entrada
deve ser uma string”).

3. Normalização da Entrada:
- Converter toda a string para minúsculas (`lower()`).
- Remover todos os caracteres não alfanuméricos usando `str.isalnum()`.
- Remover espaços em branco.

4. Tratamento de Casos de Borda:
- String vazia (`""`): retornar `True`.
- String com um único caractere: retornar `True`.

5. Verificação de Palíndromo (Complexidade O(n)):
- Utilizar algoritmo de dois ponteiros (início/fim) para comparar caracteres da string
normalizada.
- Retornar `True` somente se todos os pares de caracteres corresponderem; caso
contrário, `False`.

6. Complexidade e Uso de Memória:
- Garantir tempo de execução O(n), onde n é o comprimento da string original.
- Espaço extra O(n) devido à string normalizada.

7. Mensagens de Erro:
- Para `TypeError`, incluir mensagem descritiva de validação de tipo.

8. Constrangimentos de Implementação:
- Não usar bibliotecas externas; somente funções e métodos nativos de Python.
- Não implementar docstrings nem anotações de tipo adicionais além da assinatura.

9. Casos de Teste Obrigatórios:
a. Palíndromos válidos (com e sem pontuação e espaços):
- "A man, a plan, a canal: Panama"
- "No 'x' in Nixon"
b. Não-Palíndromos:
- "hello"
- "abc123"
c. Casos de Borda:
- String vazia: ""
- Único caractere: "x"
d. Tipos Inválidos:
- `None`, inteiros (`123`), listas (`[]`), etc., todos devem disparar `TypeError`.
