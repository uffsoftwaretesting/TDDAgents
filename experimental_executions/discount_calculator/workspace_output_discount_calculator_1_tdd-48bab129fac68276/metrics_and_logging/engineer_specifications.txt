# Especificação Técnica: Função calculate_discount

## 1. Visão Geral do Sistema
Esta especificação define a função `calculate_discount` responsável por calcular o valor de desconto e o preço final de um produto dado o preço original e a porcentagem de desconto. A função aplica fórmulas matemáticas padronizadas, garante validações rigorosas de tipo e domínio, e retorna um dicionário com valores arredondados a duas casas decimais.

## 2. Estruturas de Dados e Interfaces
- Função pública:
  - Assinatura:  
    `def calculate_discount(price, discount_percent)`
  - Parâmetros:
    - `price` (int | float): preço original do produto.  
    - `discount_percent` (int | float): porcentagem de desconto (0 a 100).
  - Retorno:
    - Dicionário com chaves:
      - `'discount'` (float): valor economizado, arredondado a duas casas decimais.  
      - `'final_price'` (float): preço a pagar após desconto, arredondado a duas casas decimais.  

Processamento interno:
1. Validar tipos de `price` e `discount_percent`.
2. Validar domínio de valores (não-negatividade e intervalo de porcentagem).
3. Calcular  
   - `discount = price * (discount_percent / 100)`  
   - `final_price = price - discount`
4. Arredondar ambas as variáveis com `round(..., 2)`.
5. Retornar o dicionário resultante.

## 3. Casos de Borda e Validações (Edge Cases)

Regras de Validação e Exceções:
- Tipo inválido:
  - Se `price` não for int ou float → raise TypeError  
  - Se `discount_percent` não for int ou float → raise TypeError
- Domínio de valores:
  - Se `price < 0` → raise ValueError  
  - Se `discount_percent < 0` ou `discount_percent > 100` → raise ValueError

Casos de Teste:

1. Casos Válidos:
   - `price=100, discount_percent=10`  
     Esperado: `{'discount': 10.00, 'final_price': 90.00}`
   - `price=59.99, discount_percent=15`  
     Verificar: `discount = 8.9985 → 9.00`, `final_price = 50.9915 → 50.99`

2. Casos de Borda:
   - `price=100, discount_percent=0`  
     Esperado: `{'discount': 0.00, 'final_price': 100.00}`
   - `price=100, discount_percent=100`  
     Esperado: `{'discount': 100.00, 'final_price': 0.00}`

3. Casos Inválidos:
   - `price=-1, discount_percent=10` → ValueError  
   - `price=100, discount_percent=-5` → ValueError  
   - `price=100, discount_percent=150` → ValueError  
   - `price='100', discount_percent=10` → TypeError  
   - `price=100, discount_percent=None` → TypeError

## 4. Contexto Técnico
- Linguagem alvo: Python 3.x (sem recursos externos além da biblioteca padrão).  
- Paradigma: programação funcional/procedural simples, única função independente.  
- Arredondamento explícito a 2 casas decimais via `round(value, 2)`.  
- Tipos estritos de entrada, uso de exceções padrão (`TypeError`, `ValueError`).  
- Saída sempre estruturada como dicionário, seguindo o padrão acordado.

## 5. Dependências Base (Core Dependencies)
- Python standard library (built-in).  
- Ferramenta de testes: pytest (inclui suporte a asserções e captura de exceções).
