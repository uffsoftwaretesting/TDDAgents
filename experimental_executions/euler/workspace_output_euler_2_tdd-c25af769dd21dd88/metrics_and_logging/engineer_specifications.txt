# Especificação Técnica: Solver de EDO – Método de Euler Explícito

## 1. Visão Geral do Sistema
Implementar uma função pura e determinística `solve` que aproxima a solução de uma equação diferencial ordinária (EDO) de primeira ordem `y' = f(t, y)` no intervalo `[t0, tf]` através do método de Euler explícito. A função deve retornar apenas o valor aproximado `y(tf)` usando uma malha uniforme de `n` passos.

## 2. Estruturas de Dados e Interfaces

Entidade principal  
- Função `solve(f, t0, tf, y0, n) -> float`

Assinatura e contratos  
- f: Callable[[float, float], float]  
  - Define a derivada `y' = f(t, y)`.  
- t0: float  
  - Tempo inicial do problema, deverá ser estritamente menor que `tf`.  
- tf: float  
  - Tempo final do problema, deverá ser estritamente maior que `t0`.  
- y0: float  
  - Condição inicial em `t0`.  
- n: int  
  - Número de subintervalos (passos) uniformes, deve ser > 0.

Retorno  
- float: aproximação de `y(tf)` após aplicar `n` iterações do método de Euler explícito.

Fluxo Interno  
1. Validar parâmetros de entrada.  
2. Calcular passo `h = (tf - t0) / n` com precisão de ponto flutuante.  
3. Iterar para k de 0 até n-1:  
   - t_k = t0 + k * h  
   - y_{k+1} = y_k + h * f(t_k, y_k)  
4. Retornar y_n.

## 3. Casos de Borda e Validações (Edge Cases)
- n ≤ 0  
  - Lançar ValueError com mensagem: “n must be a positive integer”.  
- n não inteiro  
  - Lançar TypeError: “n must be an integer”.  
- t0 >= tf  
  - Lançar ValueError: “tf must be greater than t0”.  
- t0, tf, y0 não do tipo float  
  - Lançar TypeError: “t0, tf and y0 must be floats”.  
- f não é chamável  
  - Lançar TypeError: “f must be a callable accepting (float, float) and returning float”.  
- f retorna valor não-flutuante  
  - Propagar erro ou lançar TypeError: “f must return a float”.  
- Operações de ponto flutuante resultando em overflow/NaN  
  - Propagar exceção padrão do Python, sem capturar ou mascarar.  
- Caso de estabilidade numérica  
  - Nenhuma validação explícita, mas esperado que testes cubram instabilidade para passos grandes em EDOs stiff.

## 4. Contexto Técnico
- Ambiente Python 3.8+  
- Paradigma funcional: função pura sem estado global ou efeitos colaterais.  
- Localização do módulo: `src/solve.py`  
- Sem manipulação de `sys.path`, `PYTHONPATH` ou variáveis de ambiente.  
- Nenhuma impressão, log ou I/O dentro da função.  
- A função deve executar corretamente a partir da raiz do projeto.  
- Comentários sucintos para explicar cálculo de `h` e iteração, seguindo PEP 8.
