PROMPT INICIAL ENVIADO PELO USUARIO
================================================================================
Como engenheiro de software com foco em computação científica, quero desenvolver
uma função em Python chamada rk2_ponto_medio que resolva um Problema de Valor
Inicial (PVI) de uma Equação Diferencial Ordinária (EDO) utilizando o método de
Runge-Kutta de 2ª ordem (Ponto Médio). A função deve atuar como parte do núcleo
de uma biblioteca matemática de alta performance, recebendo parâmetros com
tipagem estática rigorosa: a função da EDO f(t,y) injetada como um Callable
nativo (estritamente puro e sem efeitos colaterais), as condições iniciais t0​ e
y0​, o limite de integração t_final​ e o tamanho do passo h.
