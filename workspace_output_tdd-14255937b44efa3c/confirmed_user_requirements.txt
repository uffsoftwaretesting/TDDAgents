[Analista]: Checklist de Requisitos Técnicos para rk2_ponto_medio:

1. Assinatura da Função
- Nome: rk2_ponto_medio
- Parâmetros tipados estaticamente:
• f: Callable[[float, float], float]  (função pura sem efeitos colaterais)
• t0: float  (tempo inicial)
• y0: float  (valor inicial y(t0))
• t_final: float  (tempo final de integração)
• h: float  (tamanho do passo, h > 0)
- Retorno: float (valor y em t_final)

2. Validações de Entrada
- Verificar que f é Callable e aceita (float, float) → float; caso contrário, lançar
TypeError.
- t0, y0, t_final, h devem ser floats; h > 0; caso contrário, lançar ValueError.
- Assegurar t_final >= t0; caso contrário, lançar ValueError.

3. Lógica de Integração RK2 (Ponto Médio)
- Inicializar t = t0, y = y0.
- Enquanto t < t_final:
• Calcular passo atual h_i = min(h, t_final - t).
• k1 = f(t, y)
• y_mid = y + (h_i/2) * k1
• t_mid = t + h_i/2
• k2 = f(t_mid, y_mid)
• y = y + h_i * k2
• t = t + h_i
- Ao final do loop, retornar y.

4. Tratamento de Erros em Tempo de Execução
- Se f lançar exceção, propagar para o chamador.
- Garantir que valores intermediários sejam floats; caso contrário, lançar TypeError.

5. Performance e Manutenibilidade
- Anotar com type hints para mypy/IDE.
- Documentar comportamento e pré-condições em docstring num formato padrão (Google ou
NumPy style).
- Usar referências locais (bind-to-local) para f e variáveis críticas para otimizar o
loop.

6. Testes Unitários (TDD)
- Caso trivial: t_final == t0 → retorna y0 sem chamar f.
- Passo único exato: (t_final - t0) % h == 0 → comparações com solução analítica (e.g.,
y'=c → y0 + c·(t_final - t0)).
- Passo final ajustado: (t_final - t0) não múltiplo de h; verificar que último h_i =
remanescente e resultado compatível.
- Função f que retorna valor não float → deve disparar TypeError.
- Valores inválidos de h, t_final < t0, tipagem incorreta → ValueError/TypeError.
- Testar em ODEs conhecidas (e.g., y'=y, solução exp, y'=-ky, solução decaimento).

7. Documentação Adicional
- Incluir exemplo de uso no módulo e alertar que f deve ser pura.
- Explicar ajuste de passo final no docstring.
