# Especificação Técnica: Solver de EDO por Euler Explícito

## 1. Visão Geral do Sistema
Implementar a função `euler_explicito` em Python para resolver Problemas de Valor Inicial (PVI) de Equações Diferenciais Ordinárias (EDO) escalares usando o Método de Euler Explícito. A função deve ser pura, de alta performance e confiável, aceitando uma função `f(t, y)` como entrada e retornando apenas o valor aproximado de `y(t_final)`.

## 2. Estruturas de Dados e Interfaces

### Assinatura
```python
def euler_explicito(
    f: Callable[[float, float], float],
    t0: float,
    y0: float,
    t_final: float,
    h: float
) -> float
```

### Descrição dos Parâmetros
- `f`: Callable[[float, float], float]  
  Função que define a EDO; recebe tempo `t` e valor `y` e retorna derivada `dy/dt`.  
- `t0`: float  
  Tempo inicial do PVI.  
- `y0`: float  
  Valor inicial `y(t0)`.  
- `t_final`: float  
  Tempo de integração final, com `t_final >= t0`.  
- `h`: float  
  Tamanho do passo, com `h > 0`.

### Retorno
- `float`: aproximação de `y(t_final)`.

### Exceções Lançadas
- `TypeError` para tipos inválidos em `f`, `t0`, `y0`, `t_final` ou `h`.  
- `ValueError` para condições de domínio violadas (`h <= 0`, `t_final < t0`, número de passos não inteiro).  
- `RuntimeError` ao capturar exceções internas de `f`.

## 3. Casos de Borda e Validações (Edge Cases)

1. **Tipagem de `f`**  
   - Se `f` não for chamável ou não respeitar a assinatura `(float, float) -> float`, lança `TypeError`.
2. **Tipagem de `t0`, `y0`, `t_final`, `h`**  
   - Se qualquer um não for `float`, lança `TypeError`.
3. **Passo inválido**  
   - `h <= 0` → `ValueError("h must be positive")`.
4. **Intervalo de integração**  
   - `t_final < t0` → `ValueError("t_final must be >= t0")`.
5. **Número de passos não inteiro**  
   - `N = (t_final - t0) / h` não é inteiro dentro de uma tolerância de `1e-8` → `ValueError("Number of steps must be integer")`.
6. **Caso zero steps**  
   - Se `t_final == t0`, retorna `y0` imediatamente (N == 0).
7. **Erros em `f` durante a iteração**  
   - Capturar qualquer exceção de `f(t, y)` e reembalar em `RuntimeError("Error evaluating derivative at step i: ...")`.
8. **Manutenção de pureza**  
   - A função não deve alterar qualquer estado global.

## 4. Contexto Técnico
- Linguagem-alvo: Python 3.8+  
- Paradigma: programação funcional / pura  
- Precisão numérica: usar operações de ponto flutuante; tolerância de comparação de passos de `1e-8`.  
- Complexidade de tempo: O(N), onde N = número de passos.  
- Complexidade de espaço: O(1) adicional (variáveis locais só).  
- Nenhuma dependência de I/O ou log; é um núcleo de biblioteca.

## 5. Dependências Base (Core Dependencies)
- Bibliotecas padrão Python:
  - `typing.Callable`
  - `math.isclose` (para checar integridade de N)
- Ferramenta de testes:
  - `pytest` (para suíte TDD)
- Não há outras bibliotecas externas obrigatórias.
