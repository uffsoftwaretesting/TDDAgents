PROMPT INICIAL ENVIADO PELO USUARIO
================================================================================
Como engenheiro de software com foco em computação científica, quero desenvolver
uma função em Python chamada euler_explicito que implemente o Método de Euler
Explícito que resolva um Problema de Valor Inicial (PVI) de uma Equação
Diferencial Ordinária (EDO). A função deve ser projetada como o núcleo de uma
biblioteca matemática de alta performance e confiabilidade, recebendo parâmetros
com tipagem estática rigorosa: a função matemática do PVI passada como uma
estrutura de primeira classe nativa do Python (evitando interpretação de strings
em tempo de execução), as condições iniciais t0 e y0, o limite de integração
t_final e o tamanho do passo h.
