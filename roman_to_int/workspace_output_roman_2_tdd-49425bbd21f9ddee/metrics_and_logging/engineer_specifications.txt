# Especificação Técnica: Conversor Romano para Inteiro

## 1. Visão Geral do Sistema
O sistema fornece uma função única, `roman_to_int(s: str) -> int`, que converte uma string representando um número romano em seu valor inteiro correspondente, respeitando as regras de formação de numerais romanos e limitando o resultado ao intervalo de 1 a 3999. Entradas inválidas ou fora de domínio geram `ValueError`.

## 2. Estruturas de Dados e Interfaces

### 2.1 Assinatura
- Função: `roman_to_int`
- Entrada:  
  - s (str): string contendo o numeral romano (pode ter espaços em torno; case-insensitive)  
- Saída:  
  - int: valor numérico convertido  
- Exceções:  
  - lança `ValueError` em qualquer violação de regra ou valor fora do intervalo [1, 3999]

### 2.2 Dados Internos Esperados
- Mapeamento de símbolos básicos:  
  - I → 1, V → 5, X → 10, L → 50, C → 100, D → 500, M → 1000  
- Conjunto de pares de subtração válidos:  
  - IV (4), IX (9), XL (40), XC (90), CD (400), CM (900)

### 2.3 Fluxo de Integração
1. Pré-processa `s` (strip + uppercase).  
2. Valida caracteres e sequências.  
3. Itera sobre os símbolos para somar/subtrair valores de acordo com vizinhança e regras.  
4. Verifica resultado dentro de [1, 3999].  
5. Retorna inteiro ou lança `ValueError`.

## 3. Casos de Borda e Validações (Edge Cases)

1. Entrada ausência ou vazia  
   - Após `strip()`, string vazia → `ValueError("Entrada vazia")`.  
2. Caracteres inválidos  
   - Qualquer caractere fora de {I,V,X,L,C,D,M} → `ValueError("Caractere inválido: {c}")`.  
3. Regras de repetição  
   - I, X, C, M: no máximo 3 ocorrências consecutivas (ex.: "IIII" → erro).  
   - V, L, D: não podem repetir consecutivamente (ex.: "VV" → erro).  
4. Regras de subtração  
   - Apenas IV, IX, XL, XC, CD, CM permitidos.  
   - Qualquer outro par em que símbolo menor precede maior (ex.: "IL", "IC", "VX") → `ValueError("Subtração inválida: {par}")`.  
5. Valores fora de domínio  
   - Resultado final < 1 ou > 3999 → `ValueError("Valor fora do intervalo permitido")`.  
6. Exemplos de casos limite  
   - Mínimo válido: "I" → 1  
   - Máximo válido dentro de limites: "MMMCMXCIX" → 3999
