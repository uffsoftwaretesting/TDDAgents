[Analista]: Checklist de Requisitos Técnicos e Testáveis para a função roman_to_int(s:
            str) -> int:

1. Assinatura da Função
• Nome: roman_to_int
• Entrada: única string (s)
• Saída: inteiro
• Exceção: ValueError para qualquer entrada inválida

2. Pré-processamento de Entrada
• Remover espaços em branco no início e fim
• Verificar string vazia após strip → ValueError
• Converter toda a string para maiúsculas

3. Validação de Caracteres
• Apenas os símbolos válidos: I, V, X, L, C, D, M
• Qualquer outro caractere → ValueError

4. Regras de Repetição
• I, X, C e M: permitidos até 3 vezes consecutivas (ex.: III, XXX)
• V, L e D: não podem se repetir consecutivamente

5. Regras de Subtração
• Apenas os pares IV (4), IX (9), XL (40), XC (90), CD (400), CM (900)
• Qualquer outra combinação como IC, IL, VX, etc. → ValueError

6. Cálculo do Valor
• Mapeamento básico: I=1, V=5, X=10, L=50, C=100, D=500, M=1000
• Percorrer do primeiro ao penúltimo caractere:
– Se valor atual < valor próximo e forma par substrativo permitido → subtrair valor
atual
– Caso contrário → somar valor atual
• Somar valor do último símbolo no final

7. Limites de Valor
• Se resultado < 1 ou > 3999 → ValueError

8. Tratamento de Erros
• Em qualquer violação de regra acima → lançar ValueError com mensagem descritiva

9. Testes Unitários
9.1 Casos Válidos
• "III" → 3
• "IV" → 4
• "IX" → 9
• "LVIII" → 58
• "MCMXCIV" → 1994
• Testar entradas em minúsculas e misto-case (ex.: "mCmXcIv")
9.2 Casos Inválidos
• String vazia
• Caracteres não-romanos (ex.: "AXI")
• Repetições ilegais ("IIII", "VV")
• Combinações indevidas ("IC", "IL", "VX")
• Valor calculado fora do intervalo (ex.: "MMMM")
9.3 Casos de Borda
• "I" → 1
• "MMMCMXCIX" → 3999
