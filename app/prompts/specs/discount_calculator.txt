Act as a software engineer specialized in Python. The use case consists of calculating the discount amount applied to a product. The task is to design and implement, in pure Python without using external libraries beyond the standard library, a function that receives two numeric values (int or float), representing the original price and the discount percentage. The output must be a well-defined structure (such as a tuple or dictionary) containing the amount saved and the final price to pay, both as real numbers. The method must correctly apply the formulas discount = price * (percentage / 100) and final_price = price - discount, ensuring numeric precision and, if necessary, explicit rounding (e.g. two decimal places). The assumptions include rigorous type validation (rejecting strings, None, and non-numeric objects with TypeError) and domain validation (non-negative price and percentage between 0 and 100, with ValueError in invalid cases). The tests must include valid cases (such as price=100, discount=10), edge cases (0% and 100%), and invalid cases (incorrect types, negative values, and percentages outside the range). Documentation, docstring, or type tests must not be implemented.
