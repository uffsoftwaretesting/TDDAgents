Act as a software engineer specialized in Python. The use case consists of formatting CEP codes (Brazilian postal codes) in the standard Brazilian format. The task is to design and implement, in pure Python without using external libraries beyond the standard library, a function that receives a sequence representing a CEP as input and returns a string formatted as "XXXXX-XXX". The output must be a string containing exactly eight digits with a hyphen automatically inserted after the fifth digit. The method must validate and normalize the input, ensuring only digits are considered, accepting either strings or integers as long as they represent exactly 8 digits, and then apply the formatting through string manipulation. The assumptions include rigorous validation of types and content, rejecting invalid inputs such as strings with non-numeric characters, values with a digit count different from 8, None, or other objects, raising appropriate exceptions such as TypeError and ValueError with clear messages. The tests must include valid cases (e.g. "24350310" → "24350-310", 12345678 → "12345-678"), invalid cases (such as "1234", "abcdefgh", "123456789", None), and edge cases (such as inputs with leading zeros). Documentation, docstring, or type tests must not be implemented.
