Act as a software engineer specialized in Python. The use case consists of checking whether a string is a palindrome. The task is to design and implement, in pure Python without using external libraries, a function that receives a string as input and returns a boolean value, True for palindromes and False otherwise. The output must correctly reflect the check after normalizing the input. The method must make the check case-insensitive, remove whitespace, ignore punctuation and non-alphanumeric characters, and operate with O(n) complexity. The assumptions include rigorous type validation, raising TypeError for invalid inputs such as None, numbers, or other objects, and handling edge cases such as an empty string and single-character strings. The tests must include valid cases, non-palindrome cases, and edge cases (empty string and a single character). Documentation, docstring, or type tests must not be implemented.
