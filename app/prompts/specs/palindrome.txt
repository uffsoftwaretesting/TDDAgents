Aja como um engenheiro de software especializado em Python. O caso de uso consiste em verificar se uma string representa um palíndromo. A tarefa é projetar e implementar, em Python puro e sem uso de bibliotecas externas, uma função que receba uma string como entrada e retorne um valor booleano, sendo True para palíndromos e False caso contrário. A saída deve refletir corretamente a verificação após normalização da entrada. O método deve tornar a verificação case-insensitive, remover espaços em branco, ignorar pontuação e caracteres não alfanuméricos, e operar com complexidade O(n). As premissas incluem validação rigorosa de tipos, lançando TypeError para entradas inválidas como None, números ou outros objetos, e tratamento de comportamento para casos de borda como string vazia e strings com um único caractere. Os testes devem incluir casos válidos, casos não palíndromos, e casos de borda (string vazia e um único caractere). Não devem ser implementados testes de documentação, docstrings ou types.
