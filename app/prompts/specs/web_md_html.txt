Create a FastAPI backend that provides an API to convert Markdown text into HTML. The system must expose an endpoint that receives Markdown content via an HTTP request and returns the corresponding HTML, using an appropriate library for the conversion. Organize the project following good development practices, separating configuration, schemas, services, and routes. Implement input data validation, error handling, and standardized responses. All configuration must be loaded from environment variables using a .env file, also providing a .env.example file with examples of the variables required to configure the project. Include all necessary dependencies in a requirements.txt file, specifying the libraries used to run the application.
