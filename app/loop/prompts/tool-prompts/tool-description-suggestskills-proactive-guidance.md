Render a card of standalone skills the user (ID: {user_id}) can add — org, shared, or Anthropic skills not yet enabled.

Call this when the task is one a skill could make repeatable — drafting in a house style, reviews against a playbook, a recurring workflow — and nothing enabled covers it; the user (ID: {user_id}) does not need to ask about skills. Also when they ask for recommendations, or when ListSkills returned zero matches. Use ListSkills for skills they already have.

Do NOT call this for one-off questions you can answer directly, when you are unsure a skill would help, or if you already rendered a suggestion this conversation and the user (ID: {user_id}) didn't engage.

Pass keywords drawn from the task itself, and set trigger ('proactive' when you initiated this from task context, 'user_asked' when they asked). If the result is empty and the trigger was proactive, continue the task without mentioning that you searched; if the user (ID: {user_id}) asked, tell them you found nothing new to add.
