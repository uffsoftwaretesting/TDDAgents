# Especificação Técnica: Euler Implícito PVI Solver

## 1. Visão Geral do Sistema
Esta biblioteca oferece uma função `euler_implicito` para resolver problemas de valor inicial (PVI) de equações diferenciais ordinárias escalares usando o método de Euler implícito. O cálculo de cada passo requer a solução de uma equação não linear via método de Newton-Raphson com derivada numérica, garantindo flexibilidade e robustez em EDOs não lineares.

## 2. Estruturas de Dados e Interfaces

### 2.1 Função Principal
Nome: `euler_implicito`  
Assinatura:
```python
from typing import Callable, List

def euler_implicito(
    func: Callable[[float, float], float],
    t0: float,
    y0: float,
    t_final: float,
    h: float,
    tol: float = 1e-8,
    max_iter: int = 50
) -> List[float]:
    ...
```
Parâmetros:
- `func(t: float, y: float) -> float`  
  Função que define a EDO: dy/dt = f(t, y).
- `t0: float`  
  Tempo inicial.
- `y0: float`  
  Valor inicial y(t0).
- `t_final: float`  
  Tempo final de integração.
- `h: float`  
  Passo inicial (positivo).
- `tol: float`  
  Tolerância de convergência do solver de raízes (positivo).
- `max_iter: int`  
  Número máximo de iterações do solver de Newton-Raphson (>= 1).

Retorno:
- `List[float]`  
  Lista de valores `[y0, y1, …, y_n]` correspondentes a cada nó de tempo, inclusive o último ponto `t_final`.

### 2.2 Exceção Customizada
Classe: `ConvergenceError(Exception)`  
- Lançada quando o método de Newton-Raphson não convergir em `max_iter` iterações.  
- Deve conter mensagem descritiva indicando o passo de falha e valores correntes de `t`, `h_i` e critério de convergência.

### 2.3 Função Auxiliar (solução de raízes)
Assinatura interna (não exposta publicamente):
```python
def _newton_solver(
    phi: Callable[[float], float],
    phi_prime: Callable[[float], float],
    y_init: float,
    tol: float,
    max_iter: int
) -> float:
    ...
```
Descrição:
- Recebe `φ` e sua derivada `φ′` (numérica), chute inicial `y_init`, `tol` e `max_iter`.
- Itera:  
  y_{new} = y_{old} - φ(y_{old})/φ′(y_{old})
- Critério de parada: |y_new − y_old| < tol.
- Em falha, lança `ConvergenceError`.

## 3. Casos de Borda e Validações (Edge Cases)

1. **Tipos de Parâmetros**  
   - `func` não ser `Callable[[float, float], float]` → `ValueError`.  
   - `t0, y0, t_final, h, tol` não serem `float` → `ValueError`.  
   - `max_iter` não ser `int` → `ValueError`.

2. **Domínio de Valores**  
   - `h ≤ 0` → `ValueError`.  
   - `tol ≤ 0` → `ValueError`.  
   - `max_iter < 1` → `ValueError`.  
   - `t_final ≤ t0` → `ValueError`.

3. **Número de Passos e Ajuste do Último Passo**  
   - Calcular `n_steps = ceil((t_final - t0) / h)`.  
   - Para i em [0, n_steps-1]:
     - Se i < n_steps-1, usar `h_i = h`.  
     - Se i == n_steps-1, usar `h_i = t_final - t_i` (ajuste automático do último passo, garantindo que t_n = t_final).

4. **Convergência do Solver**  
   - Cálculo de `φ(y) = y − y_i − h_i⋅func(t_next, y)`.  
   - Derivada numérica aprox:  
     φ′(y) ≈ [φ(y + eps) − φ(y − eps)]/(2⋅eps), com `eps = 1e-6`.  
   - Se não atingir `|y_new − y_old| < tol` em `max_iter` iterações → lançar `ConvergenceError`.

## 4. Contexto Técnico
- Linguagem-alvo: **Python 3.8+** com type hints (`typing`).  
- Paradigma: Imperativo, modular, funções puras.  
- Derivada numérica padronizada com `eps = 1e-6`.  
- Complexidade computacional aproximada: O(n_steps × avg_iter).  
- Organização do código:
  - Módulo principal contendo a função `euler_implicito` e a exceção `ConvergenceError`.  
  - Módulo interno ou função auxiliar `_newton_solver` para separação de responsabilidades.  
- Documentação inline recomendada para parâmetros e exceções.

## 5. Dependências Base (Core Dependencies)
- Python 3.8+ (stdlib): `math` (ceil), `typing` (Callable, List), exceções.  
- Ferramenta de testes: **pytest** (padrão-ouro para TDD em Python).
