PLANO DE SUB-REQUISITOS TDD
================================================================================
1. FASE 0 - SETUP: Criar e ativar virtualenv Python3.8+, instalar pytest; estruturar diretórios src/ e tests/; criar arquivos vazios src/palindrome_checker.py e tests/test_palindrome.py.
2. FASE 1 - VALIDAÇÃO DE TIPO: Escrever testes unitários em tests/test_palindrome.py para garantir que is_palindrome lança TypeError com mensagem “Input must be a string, got <tipo>” para entradas não-strings (None, int, list, dict). Implementar em src/palindrome_checker.py a checagem de tipo e o lançamento do erro.
3. FASE 2 - NORMALIZAÇÃO DE STRING: Em tests/test_palindrome.py, escrever testes para uma função interna normalize_string(s) que filtra caracteres não-alfanuméricos (incluindo espaços), converte para minúsculo e retorna a string resultante. Implementar normalize_string em src/palindrome_checker.py usando apenas builtins e confirmar passagem dos testes.
4. FASE 3 - LÓGICA BÁSICA DE PALÍNDROMO: Em tests/test_palindrome.py, escrever testes para is_palindrome em casos simples (‘racecar’, ‘Level’, sem pontuação) validando True e False. Implementar em src/palindrome_checker.py a função is_palindrome que utiliza normalize_string e dois ponteiros i/j para comparação linear (O(n)).
5. FASE 4 - CASOS DE BORDA: Adicionar em tests/test_palindrome.py testes para string vazia, string de um caractere e strings contendo apenas símbolos/pontuação, confirmando retorno True. Ajustar is_palindrome se necessário para cobrir esses cenários.
6. FASE 5 - CASOS NEGATIVOS E MISTURADOS: Em tests/test_palindrome.py, incluir testes para strings com pontuação e mistura de caracteres que não sejam palíndromos (ex.: “Hello, World!”) garantindo False. Validar desempenho O(n) e uso de O(n) de espaço; refinar implementação conforme os testes.
7. FASE 6 - DOCUMENTAÇÃO E CI: Adicionar docstring PEP257 em is_palindrome e normalize_string; executar pytest com coverage, atingir cobertura mínima de 100%; configurar GitHub Actions para rodar testes automaticamente em cada commit.
================================================================================
