[Analista]: Checklist de Requisitos para Função de Verificação de Palíndromo em Python:

1. Definição da Interface:
• Função: is_palindrome(s: str) -> bool
• Parâmetro obrigatório: s (string)

2. Validação de Entrada e Tratamento de Erros:
• Se o argumento não for do tipo str, lançar TypeError com mensagem clara.

3. Normalização da String (Complexidade O(n)):
• Percorrer cada caractere da string original.
• Filtrar apenas caracteres alfanuméricos (usar str.isalnum()).
• Converter todos para minúsculas (usar str.lower()).
• Construir a string normalizada.

4. Lógica de Verificação de Palíndromo (Complexidade O(n)):
• Comparar a string normalizada com sua versão invertida (ex.: normalized ==
normalized[::-1]).
• Retornar True se iguais, False caso contrário.

5. Casos de Borda:
• String vazia ("" ) → Retornar True.
• String de um único caractere ("x") → Retornar True.

6. Testes Unitários (TDD):
a) Casos Válidos (deveriam retornar True):
- "A man, a plan, a canal: Panama"
- "RaceCar"
- "No 'x' in Nixon"
- String vazia
- "Z"
b) Casos Não Palíndromos (deveriam retornar False):
- "hello"
- "Palindrome"
- "123ab321"
c) Erros de Tipo (deveriam lançar TypeError):
- None
- 12345 (int)
- ["a", "b"] (lista)

7. Não implementar docstrings, documentação ou checagem de tipos adicionais.
